ブロック落としパズル

NEXT

遊び方

落ちてくるブロックを動かして、横一列をすき間なく埋めると消えます。一度にたくさんの列を消すほど高得点。10列消すごとにレベルが上がり、落ちる速さが上がります。ブロックが上まで積み上がるとゲームオーバーです。

スマホの操作

盤面をタップ右回転
左右にドラッグ左右に移動
下にドラッグ少しずつ落とす
下にすばやくスワイプ一気に落とす
上にすばやくスワイプホールド

画面下のボタンでも操作できます。◀ ▶ ▼ は押しっぱなしで連続移動します。

キーボードの操作

← →左右に移動
↓少しずつ落とす
スペース一気に落とす
↑ / X右回転
Z / Ctrl左回転
C / Shiftホールド
P / Esc一時停止

得点

1列 100点、2列 300点、3列 500点、4列 800点に、そのときのレベルを掛けた点数が入ります。少しずつ落とすと1マス1点、一気に落とすと1マス2点のボーナスもあります。ホールドは次のブロックが出るまでに1回だけ使えます。
