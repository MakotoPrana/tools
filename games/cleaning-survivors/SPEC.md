# おそうじサバイバー 仕様

## 概要

- 2D 見下ろし型のヴァンパイアサバイバー風（ヴァンサバライク）アクション。敵の代わりに「ゴミ」と「汚れ」が押し寄せる
- プレイヤーは移動だけを操作する。清掃ギア（武器）は自動で動き、近くのゴミを片付けていく
- 片付けたゴミは「ダスト」になって床に落ち、拾うと経験値になる。レベルアップのたびに清掃ギアやパッシブを1つ選んで強くなる
- 押し寄せるゴミの量で「大量の敵を一掃する快感」を、汚れた床がピカピカに変わる様子で「ビフォーアフターの快感」を出す
- ブラウザだけで動く（HTML5 Canvas + 素の JavaScript。ほかのゲームと同じく外部ライブラリは使わない）。スマホとパソコンの両方で遊べる

### 世界観

- 舞台: ゴミや汚れが自己増殖する「極悪ゴミ屋敷」。部屋ごとに悪霊が取り憑いている
- 主人公: 伝説の清掃員。最初は掃除機 1 本で乗り込む
- 怖さより「コミカルで爽快」を優先する。ゴミや汚れには目と口がついたゆるいキャラクター

### 勝利条件と敗北条件

- 勝利（どちらか早いほう）
  - 制限時間（10分）を生き残る
  - 部屋の「清掃度」を 100% にする
- 敗北
  - 体力（スタミナ）が 0 になる

## 画面の流れ

- （ロゴ）→ タイトル → 部屋選択 → 出撃前の確認画面 → プレイ → 結果画面
- ページを開くと、最初に Origami Works のロゴアニメーション（2秒）が流れ、そのあとタイトルが出る。アニメーションは全ゲーム共通の `games/origami-intro.js`
- プレイ中にレベルアップすると、ゲームを止めて「ギア選択」画面を重ねて出す
- プレイ中の一時停止画面からは「再開」「やり直す」「部屋選択へ」を選べる
- 結果画面からは「次の部屋へ」「もう一度」「部屋選択へ」を選べる。獲得したコインと、強化画面への導線を出す
- 部屋選択から「強化（ショップ）」と「ゴミ図鑑」に移動できる

## 操作

| 機器 | 移動 | その他 |
| --- | --- | --- |
| パソコン | WASD / 矢印キー | Space: 必殺技「ゴミ圧縮」、Esc / P: 一時停止 |
| スマホ | 画面のどこでも指を置いた位置が中心になるバーチャルスティック | 画面右下の「圧縮」ボタン、右上の一時停止ボタン |

- 攻撃ボタンはない。清掃ギアはすべて自動で動く
- ギア選択はタップ / クリック、またはキー（1〜4、矢印 + Enter）で選ぶ

## プレイ画面

- 主人公は常に画面の中央。部屋（ステージ）は画面より広く、カメラが主人公を追う
- 部屋の広さは画面の約 6 × 6 倍。外周は壁で、無限には広がらない（「部屋を掃除しきる」感覚を出すため）
- 画面上部に表示するもの
  - 経験値バーとレベル
  - 残り時間（10:00 から減る）
  - 清掃度（%）
  - 片付けたゴミの数
- 画面下部に表示するもの
  - 体力バー
  - ダストボックスのゲージ（後述）
  - 持っている清掃ギアとパッシブのアイコン（各レベル付き）

## 床の汚れマップ（このゲームの中心）

- 部屋の床を 16px 四方のマスに分け、マスごとに「汚れ度」（0〜3）を持つ
  - 3: ドロドロ（茶色・黒っぽい）
  - 2: 汚れ
  - 1: うっすら汚れ
  - 0: ピカピカ（光沢と、ときどきキラッと光るエフェクト）
- 部屋は最初、ほぼ全面が汚れ度 2〜3 から始まる
- 清掃ギアの攻撃範囲が通ったマスは汚れ度が下がる。ギアごとに「床をきれいにする力」を持つ（後述）
- 汚れの描画は、汚れ用の Canvas を 1 枚用意し、きれいになったマスだけ描き直す（毎フレーム全マスを描かない）
- ゴミや汚れモンスターが通ったマス、カビの胞子が落ちたマスは汚れ度が上がる（汚れは増殖する）

### 清掃度

- 清掃度 = 汚れ度 0 のマスの割合（%）
- 100% で即勝利。実際には後半ほど汚れの増殖が速くなるため、100% は強いビルドでないと届かない「上級者向けのもう1つの勝ち方」にする

### 床の状態による効果

| 床 | 主人公への効果 |
| --- | --- |
| ピカピカ（0） | 移動速度 +15%、ダストの回収範囲 +20% |
| うっすら（1） | なし |
| 汚れ（2） | 移動速度 −10% |
| ドロドロ（3） | 移動速度 −25% |

- 「きれいにした場所が安全地帯になり、ラインを押し広げていく」戦略が生まれるようにする
- ゴミ（敵）はピカピカの床の上では少し遅くなる（−10%）

## ゴミ（敵）

- 部屋の汚れた床と、画面の外から湧き出る。汚れ度の高いマスほど湧きやすい
- 主人公に触れると体力が減る。片付ける（HP を 0 にする）とダストを落とす
- 同時に画面に出るゴミの上限は 400 体（パフォーマンスの上限。超える分は湧かない）

| 抜け毛 | 2 | ふつう | 2 | ホコリに混ざって湧く。主人公に絡みつくと移動速度 −10%（2秒） | 小 |
| 紙くず | 4 | ふつう | 3 | まっすぐ追いかけてくる標準的なゴミ | 小 |
| 空き缶 | 6 | 速い（直進） | 5 | 主人公の方向へコロコロ転がって突っ込み、そのまま通り過ぎる | 中 |
| ペットボトル | 10 | 速い（直進） | 6 | 空き缶の強化版。壁で跳ね返る | 中 |

## ダストと経験値

- 片付けたゴミはダスト（小・中・大）を床に落とす。経験値はそれぞれ 1・5・20
- ダストは主人公の回収範囲（初期: 半径 48px）に入ると、主人公に吸い寄せられる
- 必要経験値: レベル n → n+1 に 5 + n × 4（目安。調整で変える）

### ダストボックス

- 回収したダストはダストボックスにも溜まる（容量 100）
- 満タンになると、清掃ギアの攻撃力 −30%（「吸い込み効率の低下」）。ゲージが赤く点滅し「満タン!」と出す
- 中身を空にする方法は2つ
  - **ゴミ捨て場**: 部屋に 4 か所あるゴミ捨て場に立つと、1秒で空になる。空にした量に応じてコインがもらえる
  - **ゴミ圧縮（必殺技）**: ダストボックスが 50% 以上のとき使える。中身を全部使い、画面内のゴミ全体に大ダメージ（量に比例）＋画面内の床を汚れ度 1 段下げる
- 「ゴミ捨て場まで行く（安全だが移動が必要）」か「圧縮でピンチを切り抜ける」かのリソース管理にする

## 清掃ギア（武器）

- 最大 6 つまで持てる。各ギアはレベル 1〜8
- 「床をきれいにする力」: 攻撃範囲が通ったマスの汚れ度を、この数値ぶん下げる（毎ヒット）

| ギア | 動き（ヴァンサバでの対応） | 床をきれいにする力 | 進化に必要なパッシブ | 進化後 |
| --- | --- | --- | --- | --- |
| 超強力掃除機 | 移動方向の前方に扇状の吸引範囲を出し、範囲内のゴミとダストを引き寄せつつダメージ（ナイフ / ムチ風） | 1 | バッテリー増設 | ブラックホール掃除機: 前方に吸引の渦を置き、周りのゴミを全部吸い込む |
| 高圧洗浄機 | 一番近いゴミの方向に直線の水流を発射し、貫通してノックバック（レーザー風） | 2 | 温水ボイラー | 超高温スチームカノン: 太くて長い蒸気ビーム。通った線を一気にピカピカにする |
| お掃除ロボット | 主人公の周りをクルクル回ってゴミを粉砕する（キングバイブル風） | 1 | ルンバ増設 | お掃除ロボ軍団: ロボが主人公を離れ、部屋の汚れた場所を自分で探して巡回する |
| 除菌スプレー | 全方向にミストを拡散し、一定時間残る範囲ダメージ。カビ系に 2 倍ダメージ（聖水風） | 1 | 強力漂白剤 | 酸性雨ミスト: 画面中に除菌の雨を降らせる |
| コロコロ（粘着ローラー） | 主人公の後ろについてきて、通り道のゴミを巻き取る（ガーリック / 軌跡系） | 2 | 超強力粘着テープ | 巨大圧雪ローラー: 太いローラーで通り道を全部ピカピカにし、触れたゴミを潰す |

- 最初は「超強力掃除機」だけを持っている（部屋や主人公によって変えられるようにしておく）
- 進化の条件: ギアがレベル 8、かつ対応するパッシブを持っている状態で、宝箱（中ボス・ボス・エリート個体が落とす）を開ける

## パッシブ

- 最大 6 つまで持てる。各パッシブはレベル 1〜5

| パッシブ | 効果（1レベルごと） | 進化先のギア |
| --- | --- | --- |
| バッテリー増設 | ギアの攻撃間隔 −8% | 超強力掃除機 |
| 温水ボイラー | ギアの攻撃力 +10% | 高圧洗浄機 |
| ルンバ増設 | 飛び道具・ロボの数 +1（最大 +2 まで） | お掃除ロボット |
| 強力漂白剤 | 攻撃範囲 +10% | 除菌スプレー |
| 超強力粘着テープ | 効果時間 +10% | コロコロ |
| 大容量ダストパック | ダストボックスの容量 +40、回収範囲 +20% | — |
| 防水ブーツ | 汚れた床による減速を半分にする、体力 +20 | — |
| ゴム手袋 | 受けるダメージ −1 | — |

## レベルアップ（ギア選択）

- レベルアップすると、ゲームを止めて 3 つ（強化で 4 つ）の候補から 1 つ選ぶ
- 候補は「持っているギア・パッシブのレベルアップ」と「まだ持っていない新しいギア・パッシブ」から、偏らないように選ぶ
- 候補が尽きたら「体力回復」か「コイン +10」を出す
- 選択肢を出し直す「リロール」（強化で回数が増える）

## 部屋（ステージ）

| 部屋 | 名前 | 特徴 |
| --- | --- | --- |
| 1 | ゴミ屋敷のリビング | 基本の部屋。ホコリ・紙くず・空き缶が中心 |
| 2 | 呪われたキッチン | 粘着油汚れと生ゴミが多い。床がすぐドロドロに戻る |
| 3 | カビだらけの浴室 | カビの胞子が多く、床が滑る（慣性がつく） |
| 4 | 開かずの物置 | 狭い通路と段ボールの壁。ゴミが通路から一気に押し寄せる |
| 5 | 屋敷の主の間 | 全ゴミが出る最終部屋。ボスは「ゴミ屋敷の主」 |

- 部屋 1 をクリアすると部屋 2 が開く、の順に解放する
- 部屋ごとに最高清掃度と最長生存時間を記録し、部屋選択に表示する

## 強化（ショップ）

- プレイで得たコインで、次のプレイから効く永続強化を買う

| 強化 | 効果（1段階ごと） | 最大 |
| --- | --- | --- |
| 体力 | +10 | 5 |
| 攻撃力 | +5% | 5 |
| 移動速度 | +5% | 3 |
| 回収範囲 | +10% | 3 |
| ダストボックス容量 | +20 | 3 |
| リロール | +1 回 | 3 |
| 選択肢の数 | 3 → 4 | 1 |

- 主人公の追加（例: お掃除ロボ「ルン太」— 最初のギアがお掃除ロボット）も、コインまたは条件達成で解放する

## ゴミ図鑑

- 片付けたことのあるゴミを登録し、名前・説明・片付けた総数を表示する
- まだ出会っていないゴミはシルエットと「？？？」

## 演出（Juice）

- **床がきれいになる瞬間**: マスが汚れ度 0 になると、一瞬白く光って「キュッ」と鳴る。連続すると音程を少しずつ上げる
- **吸い込み**: 掃除機の範囲に入ったゴミは、小さく縮みながら回転してノズルへ吸い込まれる。大量に吸うと「ガガガガッ！シュポポン！」と鳴る
- **ダストの回収**: ダストが連続で吸い寄せられ、拾うたびに「ポポポッ」と鳴る（同時に鳴らす数は制限する）
- **ヒット**: 被弾したゴミは白く光る。倒したときに小さな粒が飛び散る
- **ゴミ圧縮**: 画面が一瞬止まり（ヒットストップ）、画面全体が揺れて、ゴミがまとめて四角いブロックに圧縮されて消える
- **清掃度の節目**: 25 / 50 / 75% で「ピカピカ度 UP!」の表示
- 画面の揺れやフラッシュは設定でオフにできる

## サウンド

- 効果音は Web Audio API で作る（音声ファイルを使わずに合成する）
- BGM はテンポの速い軽快な曲。ボス出現時に切り替える
- 効果音と BGM の音量を別々に設定できる。最初は効果音オン

## パフォーマンス

- 目標: スマホでゴミ 400 体・ダスト 300 個が出ていても 60fps
- ゴミ・ダスト・弾はオブジェクトプールで使い回す（毎フレーム new しない）
- 当たり判定は空間ハッシュ（64px のマス）で近くのものだけ調べる
- 汚れマップは差分だけ描き直す（「床の汚れマップ」を参照）
- 画面外のゴミは描画しない

## 保存

- localStorage に保存する（キーは `cleaning-survivors-` で始める）
- 保存するもの: コイン、強化の段階、解放した部屋・主人公、部屋ごとの記録、ゴミ図鑑、設定（音量・揺れ）
- 保存に失敗しても遊べるようにする（読み書きは try/catch で囲む）

## ファイル構成

- `games/cleaning-survivors/` に、ほかのゲームと同じく以下を置く
  - `index.html` / `style.css` / `script.js` / `thumb.svg` / `SPEC.md`
- 完成したら `games/index.html` の一覧に追加する

## 開発の進め方（マイルストーン）

1. **最小プロトタイプ**: 移動・掃除機 1 本・ホコリと紙くず・ダストと経験値・レベルアップ（候補は仮）
2. **汚れマップ**: 床の汚れ度・清掃度・床による速度変化
3. **ギアとパッシブ**: 5 ギア・8 パッシブ・進化
4. **ゴミの種類と時間の流れ**: 全ザコゴミ・ギミック系・中ボス・ボス
5. **ダストボックス**: ゴミ捨て場とゴミ圧縮
6. **メタ要素**: 部屋選択・強化・図鑑・保存
7. **演出とサウンド**、スマホ操作の調整、バランス調整
