# ボクセル解体ボンバー 仕様

## 概要

- ボクセル (小さな立方体) でできた家や橋、ランドマーク、巨大な像に手榴弾を投げて壊す 3D ゲーム。描画は three.js (r128、cdnjs から読み込む)
- ブロックの **80%以上** を壊すとステージクリア。手榴弾には数の制限があり、使い切って80%に届かなければ失敗
- ページを開くと、最初に Origami Works のロゴアニメーション (games/origami-intro.js) が流れる
- 画面の文言は日本語だけ

## ファイル

| ファイル | 中身 |
| --- | --- |
| `stages.js` | 材料 (色と固さ)、形を作る道具 (箱・壁・屋根・球・円柱・円すい・ななめの柱)、5つのワールドの色、50のステージの形・手榴弾の数 (three.js を使わない) |
| `tune.js` | 自動で投げる練習相手で、各ステージのクリアに要る手榴弾の数を調べ、`GRENADES` を作る (node で動かす。ゲームでは読まない) |
| `world.js` | 家のマス目、爆発でブロックが壊れる計算、支えを失ったブロックがくずれ落ちる計算 (three.js を使わないので node でも動く) |
| `script.js` | 画面 (家・地面・手榴弾・がれき・爆発の光と煙)、視点と投げる操作、ステージの進み方、効果音 |
| `index.html` | 画面の骨組み |

## ステージ

- 5つのワールドに10ステージずつ、全50ステージ。ワールドごとに空と地面の色が変わる

| ワールド | ステージ | 中身 |
| --- | --- | --- |
| 1 はじまりの村 | 1〜10 | 物置、わらの小屋、木の小屋、風車、見張り台、教会、レンガの家、納屋、一軒家、ふたごの家 |
| 2 にぎやかな町 | 11〜20 | 五重塔、灯台、アパート、屋敷、時計塔、給水塔、学校、パン屋、石のお城、長屋 |
| 3 川と橋 | 21〜30 | 石のアーチ橋、つり橋、三連アーチ橋、太鼓橋、屋根つき橋、鉄橋、丸太の橋、水車小屋、水道橋。地面に川が流れる |
| 4 世界のランドマーク | 31〜40 | 摩天楼、凱旋門、斜塔、観覧車、鉄の塔、コロッセオ、鳥居、オランダの風車、電波塔、ピラミッド |
| 5 巨大な像 | 41〜50 | ネコ、恐竜、クマ、ゴリラ、ロボ、騎士、モアイ、女神像、スフィンクス、最後は王さまのお城 |

- ステージの形と順番、手榴弾の数は `stages.js` の `STAGES` と `GRENADES`
- 1つ前のステージをクリアすると、次のステージが選べる。ステージ選択はワールドごとに10個のタイルを並べ、次に遊ぶステージを光らせる
- ★1: クリア。★2: 95%以上壊す。★3: 手榴弾を (数 × 0.3 を切り上げた数) 以上のこしてクリア
- 星の最高記録は `localStorage` の `voxel-grenade-stars-50` に保存する (5ステージだったときの `voxel-grenade-stars` とは分けた)

### 難しさの決め方

- `tune.js` (node で動かす) の練習相手が、各ステージを3回ずつ遊び、80%に届くまでに使った手榴弾の数のまん中の値を「要る数」とする。練習相手は、地面ぎわを中心に90か所を試し、いちばん壊せる場所に、少しずらして投げる
- ワールドの中では、要る数の少ない順に並べる
- 手榴弾の数 = 要る数 × (2.2 から 1.4 へステージごとに少しずつ減る倍率) を切り上げ + (2 から 1 へ減るおまけ)。はじめは要る数の2倍以上あり、最後でも1.4倍ある
- 後半のワールドほど、根元を多く壊さないとくずれないようにして (下の collapse)、細い足の像が1発で倒れないようにする

## ボクセル

- 形は1マス単位で書き、1マスを 2 × 2 × 2 のボクセルに分けて持つ (ボクセル1つは 0.5 の大きさ)。屋根の斜面、球・円柱・円すい・ななめの柱はボクセル単位でえがいて、なめらかにする
- 爆発で壊れたボクセルは小さな破片になって飛ぶ (多いときは一部だけ)。支えを失ってくずれ落ちる部分は、2 × 2 × 2 ボクセルずつのかたまりで落ちる

## 爆発と崩れ方 (world.js)

- 材料ごとの固さ (hp): 石 1.5、レンガ・ブロンズ・モアイの石 1.3、大理石・砂岩・コンクリート 1.2、鉄 1.1、しっくい 1.0、丸太・スレート 0.9、木・屋根・扉 0.7、わら 0.5、ガラス 0.2 など (`stages.js` の `MATERIALS`)
- 爆発は半径 4.5 (ボクセル9つぶん) にとどき、爆心で 3.8 のダメージ。はなれるほど直線で弱くなり、±0.25 のばらつきがある
- ダメージはブロックの hp から引かれて残る (同じところに何度も当てると、固いブロックも壊れる)
- 爆発のあと、ブロックを6方向のつながりでかたまりに分け、次のかたまりはまるごとくずれ落ちる
  - 地面 (いちばん下の段) に接するブロックがない
  - 地面に接するボクセルが8つ未満
  - 地面に接するブロックの割合が、そのかたまりのはじめの割合の collapse 倍より少ない (根元を削ると重さに負ける)。collapse はワールド1・2 が 0.55、3 が 0.5、4 が 0.42、5 が 0.32
- 壊れたブロックと、くずれ落ちたブロックの両方を「壊した」として数える

## 操作

- タップ (クリック): その場所へ手榴弾を投げる。マウスでは、ねらう点の目印 (赤い輪) と、とぶ道すじ (点線) がカーソルについてくる。タッチでは指を置いている間に出る
- ドラッグ: 視点を家のまわりに回す (上下で見下ろす角度)
- ホイール・2本指のピンチ: 近づく・離れる
- 矢印キー: 視点を回す
- 手榴弾は放物線で目標に届くように投げ、着地から少したって (とぶ時間 + 0.9 秒) 爆発する。壁や地面ではね返り、爆発の直前は赤く点滅する
- 爆風は、ほかの手榴弾やがれきを吹き飛ばす

## 効果音

- Web Audio で作る (爆発・くずれる音・投げる音・はねる音・クリアのファンファーレ)
- 右上の ♪ で切り替え、`localStorage` の `voxel-grenade-sound` に保存する
