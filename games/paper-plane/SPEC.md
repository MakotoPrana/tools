# 窓から紙ひこうき 仕様

## 概要

- 机の上で紙ひこうき (ダーツ型) を折り、3階の窓から飛ばして飛距離を競う 3D ゲーム。描画は three.js (r128、cdnjs から読み込む)
- 飛んでいる間の動きは自前の物理 (揚力・抗力・重力と、向きを安定させる力) で決まる。プレイヤーが操作できるのは、折り方・投げる角度・力だけ
- ページを開くと、最初に Origami Works のロゴアニメーション (games/origami-intro.js) が流れる

## ファイル

| ファイル | 中身 |
| --- | --- |
| `stages.js` | 5つのステージの地面・じゃま物・風・上昇気流の数 (three.js を使わない。飛ぶ物理と画面の両方が使う) |
| `model.js` | 紙を折る形の計算、できた紙ひこうきの性質、飛ぶときの物理。three.js を使わないので node でも動く |
| `script.js` | 画面 (部屋・机・建物・原っぱ)、折る操作、カメラ、投げる操作、記録 |
| `i18n.js` | 画面の文言 (日本語・英語・中国語 (簡体字)・韓国語) |
| `index.html` | 画面の骨組みと、4言語の遊び方 |

## 画面の流れ

- タイトル (紙の色・ステージと、お手本どおり / 自由に折る を選ぶ) → 折る → 完成 → 窓から飛ばす (角度と力) → 飛ぶ (カメラが追う) → 着地 → 結果
- 結果から「もう一度投げる」(同じ紙ひこうきで、風と上昇気流が変わる)、「新しく折る」、「ステージを選ぶ」(タイトルへ。「いまの紙ひこうきで投げる」で折りなおさずにほかのステージへ)

## 言語

- 日本語・英語・中国語 (簡体字)・韓国語。最初は端末の言語 (`navigator.languages`) から選び、どれでもなければ英語
- 画面上部の選択で切り替えられ、`localStorage` の `paper-plane-lang` に保存する。切り替えたら、いまの場面 (折る手順、完成、投げる、飛ぶ、結果) の文をその場で作りなおす
- 決まった文言は `data-i18n` (文)、`data-i18n-label` (読み上げ名)、`data-i18n-title`、`data-i18n-alt` で置きかえる。遊び方は言語ごとの `.help-body[data-lang]` を出し分ける
- 見出しの書体は、日本語と英語が Dela Gothic One、中国語が ZCOOL KuaiLe、韓国語が Black Han Sans。本文は日本語と英語が M PLUS Rounded 1c、中国語と韓国語は端末の書体
- 投稿の文とハッシュタグも言語ごと (#窓から紙ひこうき、#WindowPaperPlane、#窗口纸飞机、#창문종이비행기)
- 記録の風は向きと強さの数で残し、表示するときにその言語の文にする (前の版で日本語の文のまま残した記録は、そのまま出す)

## 紙と折り方

- 紙は A4 (21cm × 29.7cm、80g/m² で約5g)。中心線にははじめから折り筋がある
- 紙は凸多角形の集まり。それぞれ、もとの紙の上の座標 (模様の位置)、いまの折った状態で机に平らに置いた座標、重なりの段を持つ
- 平らに折る: 折り線で多角形を切り分け、動く側を線で裏返して上に重ねる。重ねる段は、動く紙と、折り返した先で重なる紙のうち一番上の段の上
- 半分に折ってからは、平らに折り終えた紙を「中心線のまわりに胴を起こす角度」と「胴から翼を倒す角度 (折り線は中心線から k)」で曲げた形として計算する

| # | 手順 | 操作 |
| ---: | --- | --- |
| 1 | 左上の角をまん中へ | 角をドラッグ。指の位置に角が重なるように、2点の垂直二等分線で折れる |
| 2 | 右上の角をまん中へ | 同上 |
| 3 | 左のななめのふちをまん中へ | 同上 (前の手順でずれていても、実際の角をつまむ) |
| 4 | 右のななめのふちをまん中へ | 同上 |
| 5 | 半分に折る | 左のはしを右へドラッグ (画面上で目標の点へ向かう割合が角度になる) |
| 6 | 翼の線を決める | 左右にドラッグ。胴の高さ k は 1.2〜5.5cm (はじめは 2.6cm) |
| 7 | 右の翼を折る | 翼のはしを外へ倒すようにドラッグ |
| 8 | 左の翼を折る | 同上 |

- 手順 1〜4: 目標から 6mm 以内で離すと、ぴったりに吸いつく (ずれ 0)。3cm 以上離れたところで離したり、2cm 未満しか動かさなかったりしたら、折らずに戻す
- 割合で折る手順 (5・7・8) は、4割をこえて離すと最後まで折る
- 「おまかせで折る」でその手順をぴったりに折る。「ひとつ戻る」で前の手順へ戻る
- 完成形: 胴を左右に 82度ずつ起こし、翼は上反角 8度

### 自由に折る

- お手本の手順 1〜4 のかわりに、平らに好きなだけ折る。そのあと「半分に折る」を押すと、お手本の手順 5〜8 (半分・翼の線・右の翼・左の翼) で仕上げる
- つまむ点: 押した場所から 2cm 以内に紙の頂点があればその頂点、なければ押した場所 (紙の上だけ)。重ねる先は、紙の頂点から 8mm 以内なら頂点に、中心線から 8mm 以内なら中心線に吸いつく
- 折り線で紙が2つに分かれないとき (全部動く・どこも動かない) と、1cm 未満しか動かさなかったときは折らない
- 左右対称 (はじめは ON、`localStorage` の `paper-plane-mirror`): 折ったあと、中心線で鏡に映した線でもう一度折る。鏡に映しても同じ線 (横の線、中心線) のときは折らない。「ひとつ戻る」は2回ぶんをまとめて戻す
- 半分に折る・翼を折るでつまむ点は、紙の形から選ぶ (左右それぞれ、中心線からいちばん遠い頂点)
- 記録には折り方 (お手本 / 自由) も残し、結果の上位5つに「自由」と出す

## 紙ひこうきの性質 (model.js の analyze と flightParams)

- 平らに折り終えた紙の形を 2.5mm の升で調べて、翼の面積 (左右別)、胴の面積、翼幅、揚力の中心 (前後・左右) を求める
- 重心は、曲げた形の三角形の面積で重みをつけて求める (紙は曲げても面積が変わらない)
- 左右のそろい: 片側にしかない升の割合を 1 から引いたもの
- 揚力の傾きは翼のアスペクト比からヘルムボルトの式で求める
- つり合いの迎え角は、重心が揚力の中心よりどれだけ前にあるか (静安定) で変わる。前にあるほど小さい (速く飛ぶ)
- 胴の面積が大きいほど、横すべりに機首を向ける力 (方向安定) が強い
- 揚力の中心が重心から左右にずれていると、ずっと片方へ傾けようとする力がかかる (ずれて折ると曲がる)

## 飛ぶ (model.js の stepFlight)

- 1/240 秒ずつ進める。早送りは同じ計算を3倍の速さで回す
- 力: 重力、揚力 (失速角 0.3rad をこえると下がる)、抗力 (形の抗力 + 誘導抗力 + 失速後の板の抗力)、胴の横向きの力
- 向き: ピッチはつり合いの迎え角へ戻そうとする、ヨーは横すべりの方向へ機首を向ける、ロールは上反角の効果で横すべりした側の翼を上げる。どれも速さの2乗で強くなり、回転には減衰がかかる
- 速いほど紙がしなって、つり合いの迎え角が小さくなる (強く投げても宙返りしにくい)
- 投げるときの手ぶれ: 8m/s をこえると、こえた分の2乗で大きくなる
- 風: 投げるたびに 0〜3m/s のランダムな向き。強さに合わせて3つの正弦波の突風が加わる
- 建物の壁 (x = 0〜-0.25) を窓の穴以外で通りぬけようとすると、はね返って落ちる。部屋に戻ったら床で止まる
- 地面 (部屋の中は床) に重心が着いたら着地

## ステージ

- 窓のある部屋はどのステージでも同じ高さ (床 8m、窓 9.0〜10.3m) で、外の地面の形とじゃま物が変わる。タイトルで選び、`localStorage` の `paper-plane-stage` に残す

| # | id | 名前 | 地面 | じゃま物 | 風 (m/s) | 上昇気流 |
| ---: | --- | --- | --- | --- | --- | ---: |
| 1 | field | 原っぱ | 平ら (0m) | なし | 0〜3 | 2 |
| 2 | hill | 下り坂の町 | 壁から 6m 先から 12% で下り、-30m (約256m 先) からは平らな谷の町 | 道の両わきの家 | 0〜3 | 2 |
| 3 | city | 街なか | 平ら (0m)。幅 24m の通り | 両側のビル、歩道橋 (42m 先)、商店街のアーチ (96m 先) | 0〜1.8 | 1 |
| 4 | cliff | 海の見える崖 | 32m 先までは 0m、その先は -30m の海 | 灯台 | 1〜5 | 3 |
| 5 | tower | 高層ビル | -42m の街 (窓は地上約50m) | 下の街のビル (大通りはあける) | 1〜5 | 4 |

- じゃま物は箱 (`boxes`)。上から入ったら屋上に着地 (記録になる)、横や下から入ったら、いちばん浅い面から押し出して速さを 0.2〜0.4 倍にし、はね返って落ちる
- じゃま物の配置は種を決めた乱数で作るので、毎回同じ (物理と画面でそろう)
- 一度折った紙ひこうきは、結果の「ステージを選ぶ」→ タイトルの「いまの紙ひこうきで投げる」で、ほかのステージでも投げられる

## 上昇気流

- 投げるたびに、ステージの数だけランダムな場所に作る (窓からの距離はステージごと、横は ±14m 以内、たがいに 18m 以上離す)
- 半径 4〜8m、中心の上向きの風 1.6〜2.8m/s。中心から釣り鐘の形に弱まり、高さ 28m より上では弱まる
- 見た目: 光の粒が上っていく柱 (うすい円柱と、上る粒)。中心近く (強さ 5 割以上) に入ると「上昇気流!」と出す
- まっすぐ前にある上昇気流を通ると、原っぱで約 57m → 約 82m に伸びる


- 窓の内側 (x = -0.32、高さ 9.55m) から投げる。窓は高さ 9.0〜10.3m、幅 1.5m
- 風の強さはステージの範囲で、向きはランダム。投げるたびに変わる
- 角度 -20〜45度、力 0〜100% (秒速 2〜14m)。前回の値を `localStorage` の `paper-plane-launch` に残す
- キーボード: ↑↓ 角度、←→ 力、スペース (Enter) で投げる。飛んでいる間はスペースで早送り

## 記録

- 飛距離は、窓の真下の壁ぎわ (x = 0, z = 0) からの水平の距離。横に流されても距離に入る
- `localStorage` の `paper-plane-records` に、ステージごとのベスト (着地点つき) と上位5つ (距離・翼の幅・風・日時)、プレイした回数、投げた回数を残す。ステージがひとつだった前の版の記録は、原っぱの記録として読みこむ
- ベストの着地点には金色の旗を立てる

## X への投稿

- 結果の画面に、投稿する画像のプレビューと「結果を画像つきで投稿」のボタンを出す
- 画像 (1200×675): 折った紙ひこうきのアップ (着地点の上空で少し傾けて飛ばし、横の前から見る。まわりの屋根より 8m 上、崖では崖の上より上。画面とは別に 2倍の大きさで描いて縮める)、ゲーム名、ステージ、折り方、飛距離、自己ベストの印、翼の幅と風、横から見た飛んだ道すじ (建物と窓、地面の形、5つ前後の目もり、着地点)
- 文の頭にステージ名を入れる (【原っぱ】…)
- 文: 折り方、飛距離、自己ベストか、翼の幅と風、`#窓から紙ひこうき`。URL は `https://tools.e-seventh.com/games/paper-plane/`
- X の投稿画面 (`x.com/intent/post`) には画像を渡せないので、
  - 共有シートでファイルを渡せる端末 (`navigator.canShare({ files })`、おもにスマホ): 共有シートに画像と文を渡す。X を選ぶと画像つきで投稿できる
  - それ以外 (おもにパソコン): リンクで投稿画面を開き、同時に画像をクリップボードにコピーする。投稿画面に貼り付けてもらう。コピーできなければ画像を保存する
- 押した直後でないと共有シートやクリップボードが使えないブラウザがあるので、画像のファイルは結果を出したときに先に作っておく

## 画面

- 1画面に収める: 3D をウィンドウいっぱいに描き、その上に、上の帯 (ゲーム一覧へ・ゲーム名・遊び方)、状態のチップ (手順・風・ベスト)、下のパネル (案内・ボタン・角度と力)、タイトルと結果のカードを重ねる。遊び方は「?」で下から出す
- カメラの中心は、チップの下からパネルの上までの見える場所の真ん中にずらす (`setViewOffset`)。折るときの紙の大きさも、その高さに合わせる
- 見た目: 晴れた空の青、紙の白、日ざしのオレンジの1つの明るい見た目 (ダークモードでも同じ)。文字は Dela Gothic One (見出し・数字) と M PLUS Rounded 1c (本文)。パネルとカードは右上の角を折った紙。折る間はパネルの上に進み具合の線、飛ぶ間は画面の上に大きく距離を出す

- 部屋 (3階、床の高さ 8m) の窓ぎわに机。外は芝生の原っぱで、5m ごとの芝刈りのしま、10m ごとの距離の円弧 (120m まで)、20m ごとの風見の旗、まわりに木
- 折る間は机を真上近くから見る。翼を折るときはうしろ斜め上から。机の上の紙だけ太陽の影を落とす
- 飛ぶ間は、進む向きのうしろ斜め上から追う。部屋から出るときは窓の穴を通る。地面には高さで薄くなる丸い影を出す
