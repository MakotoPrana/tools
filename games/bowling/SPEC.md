# STRIKE LANE 仕様

## 概要

- 仕掛けのあるレーンでトリックショットを決める 3D ボウリング。描画は three.js (r128)、ボールとピンの動きは cannon.js (0.6.2) の物理演算。どちらも cdnjs から読み込む
- 全10ステージ。各ステージ2投まで
  - 1投目でピンを全部倒す: ストライククリア
  - 2投目で残りを全部倒す: スペアクリア
  - 2投で倒しきれない: 失敗 (もう一度挑戦できる)
- 各ステージに宝物がひとつある。取っても取らなくてもクリア条件は変わらない
- ページを開くと、最初に Origami Works のロゴアニメーション (games/origami-intro.js) が流れる

## 画面の流れ

- タイトル → ステージ選択 → ステージ開始 (レーンの俯瞰、タップで飛ばせる) → 投球 → 結果
- 結果画面からは「次のステージへ」(クリア時)「もう一度」「ステージ選択」を選べる
- ステージは、ひとつ前のステージをクリアすると遊べるようになる
- ステージ選択画面に、クリア数・ストライククリア数・宝物の数と、ステージごとの印 (STRIKE / SPARE、宝物のひし形) を出す
- 進み具合は localStorage の `strike-lane-progress` に保存する (ステージごとに `{ best: 'strike' | 'spare', treasure: true }`)。効果音のオン・オフは `bowling-sound`

## 宝物

- ボールの中心が宝物から 0.2m 以内に入ると取れる (ピンでは取れない)
- 取った時点で保存する (そのステージに失敗しても、取った宝物はなくならない)
- 入手済みの宝物は半透明で表示する。もう一度触れても数は増えない

## 仕掛け

- ジャンプ台・坂: 傾けた板。手前の端がレーンの面にそろう。坂の上と空中ではカーブがかからない
- 落とし穴 (丸) と谷 (四角): ボールの中心が穴の内側 3cm まで入り、レーンの高さを転がっていると落ちる。落ちたボールはレーンをすり抜ける (衝突の組を分けてある)。その投球はそこで終わり
- 壁: 動かない箱。ボールを止める
- 動く壁: 正弦波で左右に往復する。投げる前も動き続けるので、タイミングを見て投げる
- 反射板: よく跳ね返す素材 (反発係数 0.75)

## レーンの寸法 (メートル)

- 公認規格に近い値: レーン幅 1.054 (板39枚)、ファウルラインから1番ピンまで 18.29、ピンの間隔 0.3048、ガター幅 0.235
- ボール: 半径 0.108、7kg。ピン: 高さ 0.381、1.5kg。ピンの当たり判定は円すい台を3つ重ねた形

## 操作

- スワイプ: 左右で投げる位置、上へなぞって投球
  - 速さ: なぞった線の長さ。画面の高さの 12% 以下で最も遅く (時速16km)、70% 以上で最も速い (時速38km)
  - 向き: 線の出だし (最初の30%) の向き
  - カーブ: 出だしの向きと終わり (最後の30%) の向きの差。約6度までの差は手ぶれとして無視する
  - なぞっている間は線を表示し、色で速さを示す (緑→赤)。指を離すと線を0.7秒残し、そのあとボールを投げて線を消す
- キーボード: ← → 位置、A / D 向き、Q / E カーブ、スペース長押しでパワー、離して投球。R でやり直し、Esc でステージ選択
- カーブは、ファウルラインから 5m より奥でボールに横向きの力 (最大 11N) をかけて表す。力は 3m かけて最大になる。遅い球ほど長く力を受けるので大きく曲がる

## 判定

- 投球後、ボールがピットや穴に落ちる (または止まる) まで待ち、そのあとピンが止まるか4秒たったら倒れた本数を数える
- 立っているピン: 傾きが約30度以内で、置かれた台の高さに残っていて、ピンデッキより手前のレーンの上にあるもの
- 1投目のあと、倒れたピンを片付け、立っているピンはその場で起こし直す
- 物理は 1/240 秒ずつ進め、時間はすべて物理の時計で測る。描画の遅い端末でも判定がずれない
