# STRIKE LANE 仕様

## 概要

- 仕掛けのあるレーンでトリックショットを決める 3D ボウリング。描画は three.js (r128)、ボールとピンの動きは cannon.js (0.6.2) の物理演算。どちらも cdnjs から読み込む
- 10ステージで1ワールド、全10ワールド・100ステージ。各ステージ2投まで
  - 1投目でピンを全部倒す: ストライククリア
  - 2投目で残りを全部倒す: スペアクリア
  - 2投で倒しきれない: 失敗 (もう一度挑戦できる)
- 各ステージに宝物がひとつある。取っても取らなくてもクリア条件は変わらない
- 日本語・英語・中国語 (簡体字)・韓国語に対応
- ページを開くと、最初に Origami Works のロゴアニメーション (games/origami-intro.js) が流れる

## ファイル

ゲームは `js/` の ES モジュールに、役割ごとに分けてある。three.js と cannon.js は `index.html` の `<script>` で読み、グローバルの `THREE`、`CANNON` として使う。ビルドはいらない (ブラウザがモジュールをそのまま読む)。

| ファイル | 役割 |
| --- | --- |
| `js/main.js` | 入口。three.js と cannon.js が読めたか確かめてから `app.js` を読む (読めなければ案内を出す) |
| `js/app.js` | つなぎ込み。ボタン、画面の大きさ、毎フレームの処理の順番 |
| `js/config.js` | 寸法と調整値 (レーン、ボール、ピン、投げ方、物理の1ステップ) |
| `js/util.js` | 小さな道具 (clamp、localStorage など) |
| `js/events.js` | モジュールどうしの知らせ (ゲームの進行は画面に直接さわらず、出来事を知らせる) |
| `js/state.js` | 遊んでいるあいだの状態 (モード、何投目か、投げる位置、1投ごとの状態) |
| `js/i18n.js` | 言語の選択と、選んだ言語の文の取り出し |
| `js/data/i18n-data.js` | 4言語の文言と宝物の名前 |
| `js/data/stages.js` | ワールドとステージのデータ。仕掛けの書き方は冒頭のコメント |
| `js/worlds.js` | ワールドとステージの一覧 (データに寸法を渡して作る) |
| `js/records.js` | 成績の保存と集計、遊べるステージの判定 |
| `js/game.js` | 進行。ステージの読みこみ、投球、倒れた本数の判定、クリア |
| `js/audio.js` | 効果音 |
| `js/render/renderer.js` | three.js の土台 (レンダラー、シーン、カメラ、ライト) |
| `js/render/textures.js` | canvas で描くテクスチャ (床、ボール、看板、縞模様) |
| `js/render/themes.js` | ワールドごとの見た目と物理の設定 |
| `js/render/materials.js` | 使い回す材質と、捨てる処理 |
| `js/render/models.js` | ピンと宝物の形 |
| `js/physics/world.js` | cannon.js の世界 (重力、摩擦と反発の組み合わせ) |
| `js/entities/ball.js` | ボール (物理と見た目) |
| `js/entities/pins.js` | ピン (物理と見た目、並べる、立っているかの判定) |
| `js/world/environment.js` | ワールドの舞台 (レーンや床、まわりの景色と、その物理) |
| `js/stage/builder.js` | ステージの仕掛けを作る |
| `js/stage/interactions.js` | ボールと仕掛けのやりとり (物理の1ステップごと) |
| `js/ui/hud.js` | ゲーム画面に重ねる表示 (ステージ名、何投目か、宝物、案内、大きな文字) |
| `js/ui/screens.js` | メニュー (タイトル、ステージ選択、成績、結果、達成率、言語) |

| `js/input/keyboard.js` | キーボードで遊ぶ |
| `js/view/camera.js` | カメラとライトの動き |
| `js/view/aimLine.js` | 狙いの点線 |
| `index.html` | 画面の骨組みと、4言語の遊び方 |

- 依存の向き: データと設定 ← 描画・物理 ← 物と舞台 ← ステージ ← 進行 ← 表示・入力 ← つなぎ込み。進行 (`game.js`) から表示へは、`events.js` の知らせで伝える

## 画面の流れ

- タイトル → ステージ選択 (ワールドを ‹ › で切り替え) → ステージ開始 (ピンの手前から投げる位置までカメラが引いてくる。タップで飛ばせる) → 投球 → 結果
- 結果画面からは「次のステージへ」(10ステージ目なら「次のワールドへ」)「もう一度」「ステージ選択」を選べる
- タイトルとステージ選択から「成績」画面を開ける
- ステージは、ひとつ前のステージをクリアすると遊べるようになる。ワールドの最初のステージは、前のワールドの10ステージ目をクリアすると遊べる

## 言語

- 最初は端末の言語 (`navigator.languages`) から選ぶ。日本語・中国語・韓国語・英語のどれでもなければ英語
- 画面上部の選択で切り替えられ、`localStorage` の `strike-lane-lang` に保存する
- 静的な文言は `data-i18n` 属性、ボタンの読み上げ名は `data-i18n-label` 属性で置きかえる。遊び方は言語ごとの `section.help[data-lang]` を出し分ける

## 成績

- ステージごとに次を記録し、`localStorage` の `strike-lane-records` に保存する (キーは `"ワールド-ステージ"`、例 `"3-7"`)

| キー | 意味 |
| --- | --- |
| `s` | ストライククリアした |
| `p` | スペアクリアした (ストライククリアしたときも付く) |
| `st` | 宝物込みのストライク (同じ挑戦の中で宝物を取って、ストライククリア) |
| `pt` | 宝物込みのスペア (同じ挑戦の中で宝物を取って、スペアクリア。宝物は1投目でも2投目でもよい。宝物込みのストライクでも付く) |
| `t` | 宝物を持っている (ボールで触れたあと、そのステージをクリアしたときに付く。失敗したら持ち帰れない) |
| `n` | 挑戦した回数 (1投目を投げた回数) |
| `r` | 投げた回数 |
| `c` | クリアした回数 |

- ストライクを取ると、スペアも取ったことにする。前の版で保存した記録も、読みこむときにそろえる
- 全体の達成率: 1ステージにつき4つの記録と宝物の5つ、全500個のうち取った数の割合 (切り捨て)。タイトル、ステージ選択、成績画面に出す
- 成績画面: 全体の集計 (達成率、クリア・4つの記録・宝物の数、挑戦の回数) と、ワールドごとの表 (ステージごとの4つの記録・宝物・挑戦回数)
- ステージ選択のタイルにも4つの記録 (X / X◆ /◆) と宝物の印を出す。結果画面では、今回はじめて取った記録に NEW を付ける
- 1ワールドだけの頃の進み具合 (`strike-lane-progress`) があれば、ワールド1に引きつぐ

## 仕掛け (stages.js で使えるもの)

| 名前 | 動き |
| --- | --- |
| ramps | 坂・ジャンプ台。手前の端が床の面にそろう。坂の上と空中ではカーブがかからない |
| holes | 丸い落とし穴と四角い谷。ボールの中心が内側 3cm まで入り、床の高さを転がっていると落ちる |
| floors | 台 (平均台、階段の段、ピンを乗せる台)。上り階段の段の縁には小さな坂 (6度) を置き、角に当たって跳ねすぎないようにする |
| blocks | 壁。`bouncy` なら反射板 (反発係数 0.75) |
| movers | 左右に往復する壁。投げる前も動き続ける |
| walls / track | 2点を結ぶ壁と、中心線から両側にタイヤの壁を作るコース (反発係数 0.45) |
| rails | ガターをふさぐバンパー |
| bumpers | 丸い柱。当たったボールを外向きに `kick` m/s はじく |
| spinners | 中心のまわりを回り続けるバー |
| portals | ワープゲート。青 (a) に入ると、速さはそのままでオレンジ (b) から出る。`dir` があればその向きへ |
| conveyors | ベルトコンベア。上を転がるボールを `fx`, `fz` (N) で押し続ける |

- 跳ね返る物 (反射板、バンパー、タイヤ) に当たったあとやワープのあとは、ボールの回転を進む向きに合わせ直す。cannon.js 0.6.2 の摩擦は1ステップの力積で打ち切るため、実際の係数は設定値の約240倍になり、前向きの回転が残ると一瞬で転がり戻ってしまうため
- 同じ理由で、アイスリンクの摩擦は 0.0002 (ボール) と 0.0004 (ピン) という小さな値にしてある

## ステージの確かめ方

- どのステージも、ストライククリア・宝物の入手・宝物込みのストライクができることを、物理シミュレーションで確かめてある
  - 1ステージにつき400通り (位置5 × 向き3 × カーブ5 × 速さ3 の格子と、ランダムな175通り) を投げる
  - 宝物込みのストライクが見つからなかったステージは、ストライクになった投球の通り道のうち、もとの位置にいちばん近い場所へ宝物を動かす (ストライクの大半が通る場所は避ける)

## 宝物

- ボールの中心が宝物から 0.2m 以内に入ると取れる (ピンでは取れない)。持ち帰ったことになるのは、そのステージをクリアしたとき
- 入手済みの宝物は半透明で表示する。もう一度触れても「宝物込み」の記録には数える

## レーンの寸法 (メートル)

- 公認規格に近い値: レーン幅 1.054 (板39枚)、ファウルラインから1番ピンまで 18.29、ピンの間隔 0.3048、ガター幅 0.235。床はどのワールドでも z = -19.16 で終わる
- ボール: 半径 0.108、7kg。ピン: 高さ 0.381、1.5kg。ピンの当たり判定は円すい台を3つ重ねた形
- 細い道の先には、間隔を 24cm につめた三角形のピンを置く。まっすぐ当ててもストライクになりやすい (公認の間隔では真正面からだと半分くらいしか倒れきらない)

## 操作

- スワイプ: 左右で投げる位置、上へなぞって投球
  - 速さ: なぞった線の長さ。画面の高さの 12% 以下で最も遅く (時速16km)、70% 以上で最も速い (時速38km)
  - 向き: 線の出だし (最初の30%) の向き
  - カーブ: 出だしの向きと終わり (最後の30%) の向きの差。約6度までの差は手ぶれとして無視する
  - なぞっている間は線を表示し、色で速さを示す (緑→赤)。指を離すと線を0.7秒残し、そのあとボールを投げて線を消す
- キーボード: ← → 位置、A / D 向き、Q / E カーブ、スペース長押しでパワー、離して投球。R でやり直し、Esc でステージ選択
- カーブは、ファウルラインから 5m より奥でボールに横向きの力 (最大 11N、アイスリンクは半分) をかけて表す

## 判定

- 投球後、ボールが落ちる・止まる・床の奥の端を越えるまで待ち、そのあとピンが止まるか一定時間 (月面は10秒、ほかは4秒) たったら倒れた本数を数える
- 立っているピン: 傾きが約30度以内で、置かれた台の高さに残っているもの (レーンのワールドでは、ガターに落ちたピンは倒れた扱い)
- 1投目のあと、倒れたピンを片付け、立っているピンはその場で起こし直す
- 物理は 1/240 秒ずつ進め、時間はすべて物理の時計で測る。描画の遅い端末でも判定がずれない
