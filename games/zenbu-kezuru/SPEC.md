# ぜんぶ削る 仕様

鉛筆1本から始めて、実在する物を実寸大の体積のまま削り続け、最後は太陽を消し去る放置系インクリメンタルゲーム。
数値はすべて `data.js`、計算は `engine.js` (画面に依存しないので Node でも動く)、画面は `game.js`。

## 基本ループ

1. 対象をタップして手で削る (1タップ 0.1cm³ から)
2. 削った体積がそのまま通貨「削りカス (m³)」になる
3. 削りカスで道具を買うと、自動で削る速さ (毎秒の破壊量) が上がる
4. 対象の残りが 0 になると次の対象へ。削りすぎたぶんは次の対象に持ち越す
5. 富士山を削り切ると転生できる

## 道具 (全11種)

紙やすり・カッター・ハンマー・電動ドリル・解体用の重機・鉄球クレーン・採掘プラント・掘削ロボ艦隊・軌道レーザー・ブラックホール発生装置・超新星ハンマー。
ステージを進めると順に解放される (まだの道具は「？？？」で1つだけ見せる)。

- n台目の値段 = 1台目の値段 × 1.15ⁿ。まとめ買い (×1 / ×10 / 最大) あり
- 1台の毎秒の破壊量 = 1台目の値段 ÷ 元を取る秒数。秒数は上の道具ほど4倍ずつ長い (最後の2種はさらに長い)
- 同じ道具を 10・25・50・100・150…500台 そろえるたびに、その道具が ×2

## 強化

| 名前 | 効果 | 値段 |
| --- | --- | --- |
| 握力トレーニング | タップ ×3 | 3mm³ から ×40 ずつ |
| 技術革新 | すべての道具 ×2 | 5L から ×1000 ずつ |
| 道具と息を合わせる | タップに毎秒の破壊量の +2% を上乗せ | 50m³ から ×1万 ずつ |

## 放置

- 閉じている間も、毎秒の破壊量の 50% で削る。上限は 8 時間
- 戻ったら「留守の間に○○削れました (東京ドーム○杯分)」と、量の例えつきで知らせる
- 画面が裏に回っていたとき (5秒以上止まっていた) も同じ扱い
- 「完了まであと○日○時間」を常に出す (今の毎秒の破壊量のまま進んだ場合)

## 転生

- 富士山を削り切ると解放
- この周で削った総量 V から、届く記憶の数 = floor(10 × (log₁₀V − 11))。今持っている数より多くなったぶんだけもらえる (富士山で約11個、太陽で約161個)
- 記憶1個につき全体 ×1.05 (重ねがけ)
- 削りカス・道具・強化・この周のステージ倍率はなくなる。実績・記憶・スキルは残る
- 記憶で習得するスキル: オフライン上限 +4時間 / オフライン効率 +10% / 最初から道具を5台ずつ持つ / 自動発注 (一番安い道具を買い続ける。設定で ON/OFF)

## 実績 (全20)

タップ回数、道具の台数、累計の量 (お風呂・プール・東京ドーム・琵琶湖・地球)、1タップの量、放置中の破壊、富士山・地球・太陽の破壊、転生回数など。1つにつき全体 +1%。

## バランスの目安

`engine.js` を使った試算 (道具の効率が一番よいものを買い続け、最初の10分だけタップ、伸びが止まったら転生):

- 1周目: 鉛筆 約15秒、一軒家 約40分、東京ドーム 約2.5時間、富士山 約16時間
- 転生をくり返して、太陽まで 約2週間

## 表示

- 体積は大きさに合わせて mm³ / cm³ / L / m³ / km³ を切り替える
- 数は 万・億・兆・京・垓… の日本語の単位 (設定で 1.2e8 の形にも切り替えられる)
- 対象は絵文字を32マス四方のブロックに分け、各マスに厚みを持たせた「浮き彫り」の立体ボクセルで描く (`relief.js`、WebGL を直接使い外部ライブラリなし)。ふちから内側へ行くほど厚く (最大15マス)、ゆっくり左右に振れる
- 削った割合に合わせて、立体の外側の層から1個ずつ剥がれる (上のほうが少し先)。中ほど少し暗い色で、掘ると芯が見える。剥がれたブロックは手前に飛んできて落ちる
- WebGL が使えない端末では、平面のブロック絵 (`voxel.js`) で同じように剥がす
