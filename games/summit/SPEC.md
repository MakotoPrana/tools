# SUMMIT ROUTES 仕様 (仮題)

## 概要

- ひとつの大きな山を、好きな登山口から好きな目的地まで登る 3D 山登りゲーム
- 山の中には道がいくつも枝分かれしていて、同じ山頂でも経路によって難しさと景色がまったく違う
- 道の途中には難所がある。慎重に歩かないと落ちる吊り橋、スタミナを使って登る岩壁 (ゼルダの伝説 ブレス オブ ザ ワイルド のような壁登り)、振り子で谷を越えるターザンロープなど
- 高いところほど難所が多く、難しくなる。そのかわり、高いところほど遠くまで見渡せて眺めが良い
- 道の途中にチェックポイント (山小屋・祠・テント場) があり、そこでセーブできる。落ちたら最後に通ったチェックポイントからやり直す
- 描画は three.js (r128)。ロープと吊り橋の揺れは cannon.js (0.6.2) の物理演算。どちらも cdnjs から読み込む (STRIKE LANE と同じ)
- スマホとパソコンの両方で遊べる。日本語・英語・中国語 (簡体字)・韓国語に対応
- ページを開くと、最初に Origami Works のロゴアニメーション (games/origami-intro.js) が流れる

## 画面の流れ

- (ロゴ) → タイトル → 山の地図 (登山口と目的地を選ぶ) → 経路の確認 → 登山 → 到着画面
- タイトルに「つづきから」を出す。途中でやめた登山があれば、最後にセーブしたチェックポイントから再開する
- 山の地図から「記録」画面と「アルバム」(撮った景色の写真) を開ける
- 登山中の一時停止画面からは「再開」「最後のチェックポイントから」「地図を見る」「登山をやめる」を選べる
- 到着画面: かかった時間、登った高さ、落ちた回数、通った難所、見つけた展望スポット。「地図へ」「同じ道をもう一度」を選べる

## 山

- 標高 0〜1000 (ゲーム内の単位はメートル。本物の山より小さく、端から端まで歩いて約15分)
- 山はひとつ。地形は高さマップ (512×512) と、その上に置く岩・橋・小屋などの部品で作る
- 標高で4つの帯に分ける。高い帯ほど難所が多く、種類も厳しくなる

| 帯 | 標高 | 景色 | 難所の多さ (100m の道あたり) | 主な難所 |
| --- | --- | --- | ---: | --- |
| 麓 | 0〜250 | 森、田畑、沢 | 0〜1 | 丸太橋、低い段差、短いはしご |
| 中腹 | 250〜550 | 雑木林、滝、岩場 | 1〜2 | 吊り橋 (短い)、低い岩壁、ターザンロープ (1本) |
| 高所 | 550〜850 | ハイマツ、岩稜、雪渓、雲海 | 2〜3 | 長い吊り橋、高い岩壁、ロープの連続、鎖場、落石 |
| 山頂域 | 850〜1000 | 岩と氷、強い風 | 3〜4 | 壊れかけの吊り橋、オーバーハング、氷の壁、やせ尾根 |

- 600m 付近に雲海を置く。雲の下からは山頂が見えず、雲の上に出ると遠くの山並みと海が見える

## 経路

- 山の道は「チェックポイント (点)」と「区間 (線)」のつながりとして持つ (`mountain.js`)
- 区間ごとに、距離、登る高さ、難しさ (★1〜5)、そこにある難所の一覧、目安の時間を持つ
- 同じ2点のあいだに、易しいが遠回りの道と、近いが難しい道の両方があるようにする

### 登山口 (スタート)

| # | 名前 | 標高 | 特徴 |
| ---: | --- | ---: | --- |
| 1 | 南の里 | 20 | 最初から選べる。易しい道が多い入門の登山口 |
| 2 | 東の沢 | 80 | 沢沿いに登る。吊り橋と丸太橋が多い |
| 3 | 西の岩場 | 150 | 岩壁が多い。壁登りが得意な人向け |
| 4 | 北の氷河口 | 300 | 最も難しい。高所の難所が早くから出る |

- 登山口2〜4は、そのあたりのチェックポイントに一度たどり着くと選べるようになる (別の登山口から来て見つける)

### 目的地 (ゴール)

| 名前 | 標高 | 内容 |
| --- | ---: | --- |
| 滝見台 | 320 | 中腹の大滝を見下ろす展望台 |
| 天狗岩 | 580 | 雲海のすぐ上に突き出した岩。雲の上に出る瞬間が見どころ |
| 双子池 | 700 | 稜線の池。ここから山頂へ3つの道が分かれる |
| 東の肩 | 880 | 山頂の手前の小ピーク。朝日が見える |
| 山頂 | 1000 | 最終目的地。どの登山口からも行ける |

- チェックポイントは目的地にもできる。一度たどり着いたチェックポイントは、地図の上で目的地として選べる
- 登山口と目的地を選ぶと、経路の候補を最大3つ出す (最短、易しい、景色の良い)。プレイヤーは候補から選ぶか、地図の区間を自分でつないで経路を作る
- 経路はあくまで道案内で、登山中に別の道へ入ってもよい。そのときは目的地までの案内を引き直す
- 登山中は画面の端に方位、標高、次のチェックポイントまでの距離を出す。分かれ道には道標を立てる

## チェックポイント

- 種類: 山小屋 (大)、祠 (小)、テント場 (高所のみ)。1区間の目安は2〜4分、高所ほど間隔を短くする
- 触れると到着扱いになり、自動でセーブする。小屋とテント場では、手動のセーブと休憩もできる
- 休憩するとスタミナが全快する。小屋では時間を進める (朝・昼・夕・夜) こともできる
- 一度たどり着いたチェックポイントのあいだは、下りに限り地図から一瞬で移動できる (登りの近道にはならない)
- 落ちたときは、最後に通ったチェックポイントから再開する。落ちた回数は記録に残すが、罰はない

## キャラクターの動き

| 動き | 内容 |
| --- | --- |
| 歩く | ふつうの速さ。吊り橋の上でも揺れが小さい |
| 走る | 速いがスタミナを少しずつ使う。足場が細いところでは踏み外しやすい |
| そっと歩く | とても遅いが、吊り橋とやせ尾根でほとんど揺れない |
| ジャンプ | 短い段差と小さな隙間を越える。最大 1.2m の高さ、2.5m の距離 |
| つかまる | 壁、ロープ、鎖、はしごにつかまる。壁に向かって進むと自動でつかまる |
| 手を離す | 壁やロープから離れる |

- 坂がきつすぎる (45度より急) と、歩いて登れず滑り落ちる。そこは壁登りか別の道を探す
- 6m 以上の高さから落ちると、着地で転んで2秒動けない。12m 以上、または谷底に落ちると最後のチェックポイントへ戻る

### スタミナ

- 円形のゲージ (ゼルダのような) で、使っているときだけキャラクターの横に出す
- 走る、壁を登る、ロープにぶら下がる、鎖場を登ると減る。地面に立っていると回復する (1秒で約30%)
- 0 になると壁やロープから手が離れる。ゲージが少ないときは赤く点滅させる
- 標高が上がるほど回復が少し遅くなる (山頂域で 70%)。雨の日は壁で減る量が増える
- スタミナの最大値は、展望スポットを見つけると少しずつ増える (下の「眺め」を参照)

## 難所

### 吊り橋

- 板を並べた橋を、左右のロープで谷に渡したもの。長さ 10〜60m
- 橋は揺れる。揺れは「キャラクターの歩き方」「風」「橋の長さ」で決まる
  - そっと歩く: ほぼ揺れない。歩く: 少し揺れる。走る・ジャンプ: 大きく揺れる
  - 立ち止まると揺れはだんだん収まる
- 揺れが大きいと体が傾く。傾きを表すバランスのゲージを足もとに出し、傾いた方と反対に左スティック (または ← →) を入れて立て直す。立て直せずに傾ききると落ちる
- 高所の橋には「抜けた板」「腐った板 (乗って1秒で落ちる)」「突風 (風の音と旗で予告する)」がある
- 揺れは cannon.js で、板をつないだ鎖として計算する。キャラクターは物理の体ではなく、板の動きに乗る

### 岩壁 (壁登り)

- つかめる壁 (岩の質感) なら、どこでも登れる。つかめない壁 (つるつるの岩、氷) は見た目で分かるようにする
- 壁につかまると、上下左右に移動できる。登っている間はスタミナが減り続ける
- 「飛びつき」(ジャンプボタン): スタミナを一度に 25% 使って、上へ大きく 1.5m 動く
- 壁の途中に「休める出っぱり」を置き、そこではスタミナが回復する。高い壁ほど出っぱりの間隔を空ける
- オーバーハング (手前に張り出した壁) では、スタミナが 2倍の速さで減る
- 雨の日は壁が濡れて、ときどき手が滑る (少し下にずり落ちる)

### ターザンロープ

- 木や岩から下がったロープ。ジャンプして飛びつくとつかまる
- つかまっている間は、前後の入力で振り子を大きくする。ぶら下がっている間はスタミナがゆっくり減る
- 振りの向きが前になったときに手を離すと、勢いのまま飛ぶ。離すのが早すぎ・遅すぎだと届かない
- 届く範囲を、飛んだ先の地面に薄い輪で示す (麓と中腹だけ。高所からは出さない)
- ロープを連続でつかみ移る区間もある (高所・山頂域)

### そのほかの難所

| 名前 | 内容 |
| --- | --- |
| 丸太橋 | 細い丸太。吊り橋と同じバランスのゲージを使うが、揺れない |
| はしご・鎖場 | 決まった線の上だけを登る壁。スタミナの減りは壁より少ない |
| やせ尾根 | 両側が崖の細い道。風が吹くと横に押される。そっと歩くと押されにくい |
| ガレ場と落石 | 崩れやすい坂。上から石が転がってくる (音と砂ぼこりで予告) |
| 雪渓 | 滑りやすい雪の坂。止まりにくく、下りは尻すべりで速く降りられる |
| 氷の壁 | つかめない壁。途中の割れ目だけをつかんで登る |

## 眺め

- 高いところほど遠くまで見えるようにする
  - 霧の濃さ (three.js の `Fog`) を標高で変える。麓は 150m 先から霞み、山頂では 3km 先まで見える
  - 雲海の上に出ると、遠くの山並み、海、町の灯り (夜) が見える
- 山の中に「展望スポット」を全20か所置く。多くは高所と、難しい道の先にある
  - 立つとカメラが自動でゆっくり景色の方を向き、地名を出す (例: 「天狗岩からの雲海」)
  - 見つけるとアルバムに写真が入り、スタミナの最大値が少し増える (4か所ごとに +20%)
- いつでも写真を撮れる「写真モード」を置く (カメラを自由に回す、画面の表示を消す)
- 時間 (朝・昼・夕・夜) と天気 (晴れ、曇り、雨、霧) で空の色と光を変える。山頂の朝日を見ると特別な写真が入る

## 記録

- `localStorage` の `summit-save` に保存する

| キー | 意味 |
| --- | --- |
| `cp` | たどり着いたチェックポイントの一覧 |
| `starts` | 選べるようになった登山口 |
| `edges` | 通ったことのある区間 |
| `views` | 見つけた展望スポット |
| `goals` | 目的地ごとの最短時間と、使った経路 |
| `run` | 途中の登山 (登山口、目的地、経路、最後のチェックポイント、経過時間、時刻、天気) |
| `stats` | 登った高さの合計、歩いた距離、落ちた回数、難所ごとの成功・失敗 |

- 記録画面: 山の地図に通った区間を色で塗る。全区間のうち通った割合、目的地ごとの最短時間、展望スポットの数を出す
- 言語の設定は `summit-lang` に保存する (STRIKE LANE と同じ仕組み)

## 操作

| 動き | キーボード | ゲームパッド | スマホ |
| --- | --- | --- | --- |
| 移動 | WASD / 矢印 | 左スティック | 画面の左半分をなぞる (仮想スティック) |
| カメラ | マウス | 右スティック | 画面の右半分をなぞる |
| ジャンプ・飛びつき | スペース | A | ジャンプボタン |
| 走る | Shift 長押し | B 長押し | スティックを大きく倒す |
| そっと歩く | Ctrl 長押し | スティックを少し倒す | スティックを少し倒す |
| 手を離す | X | X | 離すボタン |
| 写真モード | P | Y | カメラボタン |
| 一時停止 | Esc | スタート | 右上のボタン |

- そっと歩くは、スティックの倒し方 (30% 以下) でも出せる。スマホではボタンを増やさない

## カメラ

- キャラクターのうしろ上から追う三人称のカメラ。壁や岩にめりこむときは前に寄せる
- 吊り橋とやせ尾根では少し引いて、足もとと谷が見えるようにする
- 壁登り中は壁から離れて、上の出っぱりが見える位置に置く

## ファイル (予定)

| ファイル | 中身 |
| --- | --- |

## 動作の目安

- スマホで 30fps 以上、パソコンで 60fps
- 地形は 64m 四方の区画に分け、遠い区画ほど粗くする。遠くの山並みと雲海は板の絵で描く
- 物理は 1/120 秒ずつ進め、吊り橋とロープはキャラクターの近くにあるものだけ動かす

## 作る順番

1. 動きの土台: 地形1区画、歩く・走る・ジャンプ、カメラ、スタミナ
2. 3つの主な難所: 吊り橋、岩壁、ターザンロープを試せる練習場
3. 南の里から山頂までの1本の経路と、チェックポイント、セーブ
4. 山全体の地形、4つの登山口、経路の選択と案内
5. 眺め: 標高による霧、雲海、展望スポット、写真モード
6. 残りの難所、天気と時間、記録画面、4言語

## 決まっていないこと

- 落ちたときの扱い: 今はチェックポイントへ戻るだけ。体力 (ハート) を持たせるかどうか
- 道具: ロープやピッケルなど、拾うと新しい道が開く道具を入れるか (入れると経路の選び方が広がる)
- 山の数: 今はひとつだけ。あとから別の山を足せるように `mountain.js` を山ごとに分けるか
- 制限時間や日没: 夜になると危なくなる、などの時間の制約を入れるか
