# SUMMIT ROUTES 仕様 (仮題)

## 概要

- 大きな山を、好きな登山口から好きな目的地まで登る 3D 山登りゲーム
- 山の中には道がいくつも枝分かれしていて、同じ山頂でも経路によって難しさと景色がまったく違う
- 道の途中には難所がある。慎重に歩かないと落ちる吊り橋、スタミナを使って登る岩壁 (ゼルダの伝説 ブレス オブ ザ ワイルド のような壁登り)、振り子で谷を越えるターザンロープなど
- 高いところほど難所が多く、難しくなる。そのかわり、高いところほど遠くまで見渡せて眺めが良い
- 道の途中にチェックポイント (山小屋・祠・テント場) があり、そこでセーブできる
- 体力 (ハート) がある。危険な植物に触れたり、高いところから落ちたりすると減り、なくなると最後に通ったチェックポイントからやり直す
- 山の中で道具 (ピッケル、ロープ、鉈など) を見つけると、それまで通れなかった道が通れるようになる
- 山は最初はひとつ。あとから別の山を足せる作りにする (下の「山のデータ」を参照)
- 描画は three.js (r128)。ロープと吊り橋の揺れは cannon.js (0.6.2) の物理演算。どちらも cdnjs から読み込む (STRIKE LANE と同じ)
- スマホとパソコンの両方で遊べる。日本語・英語・中国語 (簡体字)・韓国語に対応
- ページを開くと、最初に Origami Works のロゴアニメーション (games/origami-intro.js) が流れる

## 画面の流れ

- (ロゴ) → タイトル → 山の選択 → 山の地図 (登山口と目的地を選ぶ) → 経路の確認 → 登山 → 到着画面
- 山がひとつしかないうちは、山の選択を飛ばして地図へ進む
- タイトルに「つづきから」を出す。途中でやめた登山があれば、その山の最後にセーブしたチェックポイントから再開する
- 山の地図から「道具」「記録」「アルバム」(撮った景色の写真) の画面を開ける
- 登山中の一時停止画面からは「再開」「道具」「最後のチェックポイントから」「地図を見る」「登山をやめる」を選べる
- 到着画面: かかった時間、登った高さ、受けたダメージ、落ちた回数、通った難所、見つけた展望スポットと道具。「地図へ」「同じ道をもう一度」を選べる

## 時間

- 夜はない。時刻は昼で固定し、時間は進まない (あとで入れられるよう、空の色と光は1か所でまとめて決める)
- 天気 (晴れ、曇り、雨、霧) はある。山ごと、登山ごとに決まり、登山中は変わらない

## 山

- 1つめの山「天狗山」。標高 0〜1000 (ゲーム内の単位はメートル。本物の山より小さく、端から端まで歩いて約15分)
- 地形は高さマップ (512×512) と、その上に置く岩・橋・小屋などの部品で作る
- 標高で4つの帯に分ける。高い帯ほど難所が多く、種類も厳しくなる

| 帯 | 標高 | 景色 | 難所の多さ (100m の道あたり) | 主な難所 |
| --- | --- | --- | ---: | --- |
| 麓 | 0〜250 | 森、田畑、沢 | 0〜1 | 丸太橋、低い段差、短いはしご、イラクサ |
| 中腹 | 250〜550 | 雑木林、滝、岩場 | 1〜2 | 吊り橋 (短い)、低い岩壁、ターザンロープ (1本)、ウルシ、イバラ |
| 高所 | 550〜850 | ハイマツ、岩稜、雪渓、雲海 | 2〜3 | 長い吊り橋、高い岩壁、ロープの連続、鎖場、落石、毒の花畑 |
| 山頂域 | 850〜1000 | 岩と氷、強い風 | 3〜4 | 壊れかけの吊り橋、オーバーハング、氷の壁、やせ尾根 |

- 600m 付近に雲海を置く。雲の下からは山頂が見えず、雲の上に出ると遠くの山並みと海が見える
- 帯の境目の標高と中身は山ごとに決める (上の表は天狗山のもの)

### 別の山

- 天狗山の山頂に一度たどり着くと、2つめの山が選べるようになる。以降も、ひとつ前の山の山頂で次の山が開く
- 山ごとに、地形、帯、登山口、目的地、チェックポイント、難所、危険な植物、展望スポット、置いてある道具が違う
- 見つけた道具は、どの山でも使える (山をまたいで持ち越す)。前の山で見つけた道具で、次の山の近道が開くこともある
- 体力とスタミナの最大値も、山をまたいで持ち越す

## 山のデータ

- 山はひとつにつき1ファイル (`mountains/<山のid>.js`) で、`mountains/index.js` に並び順と開く条件を書く
- 新しい山を足すときは、ファイルを1つ増やして `index.js` に1行足すだけでよく、`script.js` は変えない
- 山のファイルに書くもの

| 項目 | 中身 |
| --- | --- |
| `id`, `name` | 山の id (保存のキーに使う) と、4言語の名前 |
| `terrain` | 高さマップの画像、大きさ、最高標高、雲海の高さ、まわりの景色 (遠くの山並み、海など) |
| `bands` | 標高の帯 (境目の標高、草木、地面の色、風の強さ) |
| `checkpoints` | チェックポイント (位置、種類、名前) |
| `edges` | 区間 (両端のチェックポイント、通り道の点、難しさ、難所、必要な道具) |
| `starts`, `goals` | 登山口と目的地、それぞれが選べるようになる条件 |
| `obstacles` | 難所の置き場所と細かい設定 (橋の長さ、壁の高さ、ロープの長さなど) |
| `plants` | 危険な植物の種類と生えている範囲 |
| `items` | 置いてある道具と消耗品 |
| `views` | 展望スポット (位置、向き、4言語の名前) |
| `weather` | 出る天気とその割合 |

## 経路

- 山の道は「チェックポイント (点)」と「区間 (線)」のつながりとして持つ
- 区間ごとに、距離、登る高さ、難しさ (★1〜5)、そこにある難所の一覧、必要な道具、目安の時間を持つ
- 同じ2点のあいだに、易しいが遠回りの道と、近いが難しい道の両方があるようにする
- 道具が必要な区間は、地図の上で点線と道具の印で表す。道具がないと入口で引き返す (見えない壁ではなく、氷の壁や崖など見て分かる形にする)

### 登山口 (スタート) ─ 天狗山

| # | 名前 | 標高 | 特徴 |
| ---: | --- | ---: | --- |
| 1 | 南の里 | 20 | 最初から選べる。易しい道が多い入門の登山口 |
| 2 | 東の沢 | 80 | 沢沿いに登る。吊り橋と丸太橋が多い |
| 3 | 西の岩場 | 150 | 岩壁が多い。壁登りが得意な人向け |
| 4 | 北の氷河口 | 300 | 最も難しい。高所の難所が早くから出る。ピッケルがないと最初の氷の壁を越えられない |

- 登山口2〜4は、そのあたりのチェックポイントに一度たどり着くと選べるようになる (別の登山口から来て見つける)

### 目的地 (ゴール) ─ 天狗山

| 名前 | 標高 | 内容 |
| --- | ---: | --- |
| 滝見台 | 320 | 中腹の大滝を見下ろす展望台 |
| 天狗岩 | 580 | 雲海のすぐ上に突き出した岩。雲の上に出る瞬間が見どころ |
| 双子池 | 700 | 稜線の池。ここから山頂へ3つの道が分かれる |
| 東の肩 | 880 | 山頂の手前の小ピーク。山頂と雲海を一緒に見渡せる |
| 山頂 | 1000 | 最終目的地。どの登山口からも行ける。ここに着くと次の山が開く |

- チェックポイントは目的地にもできる。一度たどり着いたチェックポイントは、地図の上で目的地として選べる
- 登山口と目的地を選ぶと、経路の候補を最大3つ出す (最短、易しい、景色の良い)。プレイヤーは候補から選ぶか、地図の区間を自分でつないで経路を作る
- 候補には、いま持っている道具で通れる道だけを使う。道具があればもっと近い道があるときは「◯◯があれば近道できる」と添える
- 経路はあくまで道案内で、登山中に別の道へ入ってもよい。そのときは目的地までの案内を引き直す
- 登山中は画面の端に方位、標高、次のチェックポイントまでの距離を出す。分かれ道には道標を立てる

## チェックポイント

- 種類: 山小屋 (大)、祠 (小)、テント場 (高所のみ)。1区間の目安は2〜4分、高所ほど間隔を短くする
- 触れると到着扱いになり、自動でセーブする。小屋とテント場では、手動のセーブと休憩もできる
- 触れると体力とスタミナが全快する
- 山小屋では、消耗品 (薬草、携帯食) を1登山につき1回、袋の上限まで補充できる
- 一度たどり着いたチェックポイントのあいだは、下りに限り地図から一瞬で移動できる (登りの近道にはならない)

## 体力

- ハートで表す。最初は3つ、最大で8つ。画面の左上に出す。ハートは 1/4 ずつ減る
- 減るのは次の2つ
  - 危険な植物に触れる (下の「危険な植物」を参照)
  - 高いところから落ちる (下の「落下」を参照)
- 0 になると、最後に通ったチェックポイントから体力とスタミナが全快の状態でやり直す。それまでに見つけた道具と展望スポットは失わない。使った消耗品は戻らない
- 回復: チェックポイントに触れる (全快)、薬草を使う (ハート2つ)、清水 (沢や池のそばの湧き水) を飲む (ハート1つ、何度でも)
- 最大値: 山の中にある「お守り」を4つ集めるごとにハートが1つ増える。お守りは祠に納められていて、天狗山には8つある (ハート5つまで)。残りは別の山で増やす

### 落下

| 落ちた高さ | 結果 |
| --- | --- |
| 6m 未満 | なにもない |
| 6〜12m | 着地で転んで1秒動けない。ハート 1/2 減る |
| 12〜20m | 2秒動けない。ハート1つ半減る |
| 20m 以上 | ハートが全部なくなる |
| 谷底・滝つぼ (地図の外) | ハートが全部なくなる |

- 落ちた高さは、足場を離れたところと着地したところの差で測る。斜面を転がり落ちたときは、止まるまでの高さの差で測る
- 雪渓の上や深い水に落ちたときは、ダメージを半分にする
- 吊り橋から落ちても、すぐ下に谷底がなければ同じ表で決める (低い橋は落ちても戻れる)

### 危険な植物

| 名前 | 帯 | 触れたとき | 見分け方 |
| --- | --- | --- | --- |
| イラクサ | 麓・中腹 | ハート 1/4 減る。1秒間は同じ草でもう減らない | 道ばたの細かい毛のある草。触れるとチクッという音 |
| ウルシ | 中腹 | 「かぶれ」になる。10秒間、2秒ごとにハート 1/4 減る | 赤みのある葉。秋色の葉が目印 |
| イバラ | 中腹・高所 | ハート 1/2 減り、少し押し返される。壁やロープに巻きついているものは、つかんでいる手が離れる | トゲのあるつる。岩壁やロープに絡んでいる |
| 毒の花 (トリカブト) | 高所 | 花畑の中にいる間、1秒ごとにハート 1/4 減る | 紫の花。花畑はたいてい近道の上にある |

- どれも見て分かるようにし、初めて近づいたときに名前と注意を短く出す
- かぶれは清水で洗うか、薬草を使うと治る
- 鉈で刈ったり、手袋で防いだりできる (下の「道具」を参照)。刈った植物はその登山の間は生えてこない

## 道具

- 山の中で見つける。宝箱のように置いてあるもの、小屋の人からもらうもの、難しい道の先にあるものがある
- 道具は一度見つけるとずっと持っている。消耗品は数がある
- 持っている道具は、ほとんどがその場に合わせて自動で使われる (ピッケルは氷の壁につかまると自動で使う)。自分で使う道具は「使う」ボタンで、近くにある使える場所に合わせて選ばれる

### 道具 (ずっと持っているもの)

| 名前 | 天狗山で見つかる場所 | できるようになること | 開く道 |
| --- | --- | --- | --- |
| 鉈 | 南の里の小屋 (最初の区間) | イバラとウルシを刈る (「使う」で振る) | 植物にふさがれた近道 |
| 革手袋 | 東の沢の奥 | イラクサとイバラに触れてもダメージを受けない。雨の日も壁で手が滑らない | イバラの絡んだ岩壁 |
| ロープ | 滝見台 | 「ロープ掛け」(杭の印) から崖を降りる・登る。スタミナを使わない | 崖を下る近道、滝の裏の道 |
| 鉤縄 | 天狗岩の先の岩稜 | 離れた「かぎ掛け」(金具の印) をねらって引き寄せられる。最大 15m | 谷をまたぐ近道、ロープの届かない高い岩棚 |
| ピッケル | 双子池の小屋 | 氷の壁をつかんで登れる。雪渓で滑ってもすぐ止まれる | 北の氷河口からの道、山頂直下の氷の壁 |
| アイゼン | 東の肩への途中 | 雪渓と氷の上で滑らない。強い風でも押されにくい | 山頂域の雪の稜線 |

- 道具ごとに、それがないと通れない区間を各山に2〜3本用意する。どの道具も、なくても山頂へ行ける道は必ず残す
- 新しい道具を見つけると、それで通れるようになった区間を地図の上で光らせる

### 消耗品

| 名前 | 効果 | 袋の上限 | 手に入る場所 |
| --- | --- | ---: | --- |
| 薬草 | ハートを2つ回復し、かぶれを治す | 5 | 山小屋、道ばた (毒草とまちがえないよう、白い花で見分ける) |
| 携帯食 | スタミナを全快し、30秒間スタミナの減りを半分にする | 3 | 山小屋 |

- 消耗品は一時停止画面の「道具」か、キーボードの数字キーですぐ使える
- 消耗品の数は山をまたいで持ち越す

## キャラクターの動き

| 動き | 内容 |
| --- | --- |
| 歩く | ふつうの速さ。吊り橋の上でも揺れが小さい |
| 走る | 速いがスタミナを少しずつ使う。足場が細いところでは踏み外しやすい |
| そっと歩く | とても遅いが、吊り橋とやせ尾根でほとんど揺れない。危険な植物のすき間をすり抜けやすい (当たり判定が小さくなる) |
| ジャンプ | 短い段差と小さな隙間を越える。最大 1.2m の高さ、2.5m の距離 |
| つかまる | 壁、ロープ、鎖、はしごにつかまる。壁に向かって進むと自動でつかまる |
| 手を離す | 壁やロープから離れる |
| 使う | 近くの使える場所に合わせて道具を使う (鉈で刈る、ロープを掛ける、鉤縄を投げる) |

- 坂がきつすぎる (45度より急) と、歩いて登れず滑り落ちる。そこは壁登りか別の道を探す

### スタミナ

- 円形のゲージ (ゼルダのような) で、使っているときだけキャラクターの横に出す
- 走る、壁を登る、ロープにぶら下がる、鎖場を登ると減る。地面に立っていると回復する (1秒で約30%)
- 0 になると壁やロープから手が離れる。ゲージが少ないときは赤く点滅させる
- 標高が上がるほど回復が少し遅くなる (山頂域で 70%)。雨の日は壁で減る量が増える
- スタミナの最大値は、展望スポットを見つけると少しずつ増える (下の「眺め」を参照)

## 難所

### 吊り橋

- 板を並べた橋を、左右のロープで谷に渡したもの。長さ 10〜60m
- 橋は揺れる。揺れは「キャラクターの歩き方」「風」「橋の長さ」で決まる
  - そっと歩く: ほぼ揺れない。歩く: 少し揺れる。走る・ジャンプ: 大きく揺れる
  - 立ち止まると揺れはだんだん収まる
- 揺れが大きいと体が傾く。傾きを表すバランスのゲージを足もとに出し、傾いた方と反対に左スティック (または ← →) を入れて立て直す。立て直せずに傾ききると落ちる
- 高所の橋には「抜けた板」「腐った板 (乗って1秒で落ちる)」「突風 (風の音と旗で予告する)」がある。アイゼンがあると突風で押されにくい
- 揺れは cannon.js で、板をつないだ鎖として計算する。キャラクターは物理の体ではなく、板の動きに乗る

### 岩壁 (壁登り)

- つかめる壁 (岩の質感) なら、どこでも登れる。つかめない壁 (つるつるの岩、氷) は見た目で分かるようにする。氷の壁はピッケルがあればつかめる
- 壁につかまると、上下左右に移動できる。登っている間はスタミナが減り続ける
- 「飛びつき」(ジャンプボタン): スタミナを一度に 25% 使って、上へ大きく 1.5m 動く
- 壁の途中に「休める出っぱり」を置き、そこではスタミナが回復する。高い壁ほど出っぱりの間隔を空ける
- オーバーハング (手前に張り出した壁) では、スタミナが 2倍の速さで減る
- 雨の日は壁が濡れて、ときどき手が滑る (少し下にずり落ちる)。革手袋があれば滑らない
- 壁にイバラが絡んでいるところがある。手で触れるとダメージを受けて手が離れる。よけて登るか、革手袋で防ぐ

### ターザンロープ

- 木や岩から下がったロープ。ジャンプして飛びつくとつかまる
- つかまっている間は、前後の入力で振り子を大きくする。ぶら下がっている間はスタミナがゆっくり減る
- 振りの向きが前になったときに手を離すと、勢いのまま飛ぶ。離すのが早すぎ・遅すぎだと届かない
- 届く範囲を、飛んだ先の地面に薄い輪で示す (麓と中腹だけ。高所からは出さない)
- ロープを連続でつかみ移る区間もある (高所・山頂域)。イバラの巻きついたロープは鉈で刈ってからつかむ

### そのほかの難所

| 名前 | 内容 |
| --- | --- |
| 丸太橋 | 細い丸太。吊り橋と同じバランスのゲージを使うが、揺れない |
| はしご・鎖場 | 決まった線の上だけを登る壁。スタミナの減りは壁より少ない |
| やせ尾根 | 両側が崖の細い道。風が吹くと横に押される。そっと歩くと押されにくい |
| ガレ場と落石 | 崩れやすい坂。上から石が転がってくる (音と砂ぼこりで予告)。当たるとハート 1/2 減り、はじき飛ばされる |
| 雪渓 | 滑りやすい雪の坂。止まりにくく、下りは尻すべりで速く降りられる。アイゼンで滑らなくなる |
| 氷の壁 | ピッケルがあれば登れる。ないときは途中の割れ目だけをつかんで登る (一部の壁だけ) |

## 眺め

- 高いところほど遠くまで見えるようにする
  - 霧の濃さ (three.js の `Fog`) を標高で変える。麓は 150m 先から霞み、山頂では 3km 先まで見える
  - 雲海の上に出ると、遠くの山並みと海が見える。別の山を足したら、その山も遠くに見えるようにする
- 天狗山には「展望スポット」を20か所置く。多くは高所と、難しい道や道具が必要な道の先にある
  - 立つとカメラが自動でゆっくり景色の方を向き、地名を出す (例: 「天狗岩からの雲海」)
  - 見つけるとアルバムに写真が入り、スタミナの最大値が少し増える (4か所ごとに +20%)
- いつでも写真を撮れる「写真モード」を置く (カメラを自由に回す、画面の表示を消す)
- 天気で空の色と光を変える。霧の日は眺めが悪いかわりに、霧が晴れる瞬間 (一部の展望スポット) に特別な写真が入る

## 動作の目安

- スマホで 30fps 以上、パソコンで 60fps
- 地形は 64m 四方の区画に分け、遠い区画ほど粗くする。遠くの山並みと雲海は板の絵で描く
- 物理は 1/120 秒ずつ進め、吊り橋とロープはキャラクターの近くにあるものだけ動かす
- 山のデータは、その山を選んだときに読み込む

## 作る順番

1. 動きの土台: 地形1区画、歩く・走る・ジャンプ、カメラ、スタミナ、体力と落下のダメージ
2. 3つの主な難所: 吊り橋、岩壁、ターザンロープと、イラクサ・イバラを試せる練習場
3. 山のデータの形を決め、天狗山の南の里から山頂までの1本の経路と、チェックポイント、セーブ
4. 天狗山全体の地形、4つの登山口、経路の選択と案内
5. 道具: 鉈とロープから。道具が必要な区間と、地図での見せ方
6. 眺め: 標高による霧、雲海、展望スポット、写真モード
7. 残りの難所・植物・道具、天気、記録画面、4言語
8. 2つめの山 (山のデータを足すだけで動くことを確かめる)

## 決まっていないこと

- 2つめの山の中身 (テーマ、標高、新しい難所と道具)
- 道具を増やすか: グライダー (高いところから滑空して下りる) など、下りを楽しくする道具
- 体力が0になったときに、拾ったばかりの道具 (まだチェックポイントを通っていないもの) を失うかどうか。今は失わない
- 夜は今は入れない。入れるなら、夜にしか開かない道や見えない景色 (町の灯り、星空) と一緒に考える
