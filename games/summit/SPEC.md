# SUMMIT ROUTES 仕様 (仮題)

## 概要

- 大きな山を、好きな登山口から好きな目的地まで登る 3D 山登りゲーム
- 山の中には道がいくつも枝分かれしていて、同じ山頂でも経路によって難しさと景色がまったく違う
- 歩くより「登る」のが中心のゲーム。山は断崖絶壁が多く、高さの大部分は岩壁を登って稼ぐ。壁登りは左右の手を別々に動かして、つかみやすいホールドを選んでつかむ
- ほかにも、慎重に歩かないと落ちる吊り橋や丸太橋、振り子で谷を越えるターザンロープなどの難所がある
- 高いところほど難所が多く、難しくなる。そのかわり、高いところほど遠くまで見渡せて眺めが良い
- 道の途中にチェックポイント (山小屋・祠・テント場) があり、そこでセーブできる
- 体力 (ハート) がある。危険な植物に触れたり、高いところから落ちたりすると減り、なくなると最後に通ったチェックポイントからやり直す
- 山の中で道具 (ピッケル、ロープ、鉈など) を見つけると、それまで通れなかった道が通れるようになる
- 今は山をひとつ (天狗山) だけ作る。ただし、あとから別の山を足せる作りにしておく (下の「山のデータ」を参照)
- 描画は three.js (r128) で、cdnjs から読み込む (STRIKE LANE と同じ)。キャラクター・吊り橋・ロープの動きは自前の簡単な計算で、物理エンジンは使わない
- スマホとパソコンの両方で遊べる。日本語・英語・中国語 (簡体字)・韓国語に対応
- ページを開くと、最初に Origami Works のロゴアニメーション (games/origami-intro.js) が流れる

## 画面の流れ

- (ロゴ) → タイトル → 山の選択 → 山の地図 (登山口と目的地を選ぶ) → 経路の確認 → 登山 → 到着画面
- 山がひとつしかないうちは、山の選択を飛ばして地図へ進む
- タイトルに「つづきから」を出す。途中でやめた登山があれば、その山の最後にセーブしたチェックポイントから再開する
- タイトルから「道具」「記録」「アルバム」(撮った景色の写真) の画面を開ける
- 登山中の一時停止画面からは「再開」「道具」「最後のチェックポイントから」「地図を見る」「登山をやめる」を選べる
- 登山中はいつでも、🗺 ボタン (キーボードは M) で地図を重ねて出せる。いまいる場所 (三角の印)、選んだ経路、次のチェックポイントと目的地が分かる。ゲームは止まらないので、使い終わったら閉じる
- 到着画面: かかった時間、登った高さ、受けたダメージ、落ちた回数、通った難所、見つけた展望スポットと道具。「地図へ」「同じ道をもう一度」を選べる

## 時間

- 夜はない。時刻は昼で固定し、時間は進まない (あとで入れられるよう、空の色と光は1か所でまとめて決める)
- 天気 (晴れ、曇り、雨、霧) はある。山ごと、登山ごとに決まり、登山中は変わらない

## 山

- 1つめの山「天狗山」。標高 0〜500 (ゲーム内の単位はメートル。本物の山より小さく、裾の半径は約 640m。南の里から山頂まで約10分)
- 移動ばかりにならないよう、道のりを短くして難所を詰めて置く (1つの区間に難所が2〜5つ。難所と難所のあいだは歩いて30秒ほど)
- 地形は計算で作る: 半径ごとの標高 (麓はなだらか、上ほど急) に、向きによる張り出し・尾根・ゆるいでこぼこを足す。その上に道の棚、チェックポイントの広場、谷、岩壁の段を重ねる (`terrain.js` の冒頭のコメント)
- 断崖の帯: 標高 16m ごとに「なだらかな段」と「切り立った崖」をくり返す (`terrain.cliffs`)。崖の帯の位置はノイズで波打たせる。道とチェックポイントのまわり 14m は崖を弱め、道が溝や土手にならないようにする
- 区間の登りの半分以上を岩壁が受け持つ (1つの区間に壁が1〜4枚、高さ 8〜34m)。道の坂はゆるくなり、歩く時間は短くなる
- 道から外れたところは、麓 (約22度) は歩けるが、中腹から上は45度より急で歩けない。だから中腹から上は道を通るしかない
- 標高で4つの帯に分ける。高い帯ほど難所が多く、種類も厳しくなる

| 帯 | 標高 | 景色 | 難所の多さ (100m の道あたり) | 主な難所 |
| --- | --- | --- | ---: | --- |
| 麓 | 0〜125 | 森、田畑、沢 | 約1 | 丸太橋、低い段差、短いはしご、イラクサ |
| 中腹 | 125〜275 | 雑木林、滝、岩場 | 1〜1.5 | 吊り橋 (短い)、低い岩壁、ターザンロープ (1本)、ウルシ、イバラ |
| 高所 | 275〜425 | ハイマツ、岩稜、雪渓、雲海 | 1.5〜2 | 長い吊り橋、高い岩壁、ロープの連続、鎖場、落石、毒の花畑 |
| 山頂域 | 425〜500 | 岩と氷、強い風 | 約2 | 壊れかけの吊り橋、オーバーハング、氷の壁、やせ尾根 |

- 275m に雲海を置く。雲の下からは山頂が見えず、雲の上に出ると遠くの山並みと海が見える。雲の中は霧で真っ白になる
- 帯の境目の標高と中身は山ごとに決める (上の表は天狗山のもの)

### 別の山 (今は作らない)

- 今は天狗山だけ。2つめ以降の山は作らないが、足したときに次のように動くよう作っておく
- ひとつ前の山の山頂に一度たどり着くと、次の山が選べるようになる
- 山ごとに、地形、帯、登山口、目的地、チェックポイント、難所、危険な植物、展望スポット、置いてある道具が違う
- 見つけた道具は、どの山でも使える (山をまたいで持ち越す)。前の山で見つけた道具で、次の山の近道が開くこともある
- 体力とスタミナの最大値も、山をまたいで持ち越す

## 山のデータ

- 山はひとつにつき1ファイル (`mountains/<山のid>.js`) で、`mountains/index.js` に並び順と開く条件を書く
- 新しい山を足すときは、ファイルを1つ増やして `index.js` に1行足すだけでよく、`script.js` は変えない
- 山のファイルに書くもの

| 項目 | 中身 |
| --- | --- |
| `id`, `name` | 山の id (保存のキーに使う) と、4言語の名前 |
| `terrain` | 山の形 (標高と半径の組)、張り出しと尾根、でこぼこの大きさ、海岸と海の高さ、雲海の高さ |
| `bands` | 標高の帯 (境目の標高、草木、地面の色、風の強さ) |
| `checkpoints` | チェックポイント (向き・標高、種類、名前、清水や池の有無) |
| `edges` | 区間 (両端のチェックポイント、回る向き、難所の並び)。通り道は、山を回りながら決まった傾きで登るよう自動で作る |
| `starts`, `goals` | 登山口と目的地、それぞれが選べるようになる条件 |
| `edges[].obstacles` | 区間の上の難所と細かい設定 (橋の長さ、壁の高さと休める出っぱり、ロープの本数、抜けた板・腐った板、突風など)。必要な道具は難所の種類から決まる |
| `plants` | 危険な植物の種類と生えている範囲 |
| `items` | 置いてある道具と消耗品 |
| `views` | 展望スポット (位置、向き、4言語の名前) |
| `weather` | 出る天気とその割合 |
| `scenery` | 景色の飾り (滝、里の家) |

- 道の傾きは、チェックポイントのまわりを平らにしたうえで 6m ごとに見て、どこも 37 度以下に収まるようにしてある (壁の高さと置き場所で調整)

## 経路

- 山の道は「チェックポイント (点)」と「区間 (線)」のつながりとして持つ
- 区間ごとに、距離、登る高さ、難しさ (★1〜5)、そこにある難所の一覧、必要な道具、目安の時間を持つ
- 同じ2点のあいだに、易しいが遠回りの道と、近いが難しい道の両方があるようにする
- 道具が必要な区間は、地図の上で点線と道具の印で表す。道具がないと入口で引き返す (見えない壁ではなく、氷の壁や崖など見て分かる形にする)

### 登山口 (スタート) ─ 天狗山

| # | 名前 | 標高 | 特徴 |
| ---: | --- | ---: | --- |
| 1 | 南の里 | 10 | 最初から選べる。易しい道が多い入門の登山口 |
| 2 | 東の沢 | 40 | 沢沿いに登る。吊り橋と丸太橋が多い |
| 3 | 西の岩場 | 75 | 岩壁が多い。壁登りが得意な人向け |
| 4 | 北の氷河口 | 150 | 最も難しい。高所の難所が早くから出る。ピッケルがないと最初の氷の壁を越えられない |

- 登山口2〜4は、そのあたりのチェックポイントに一度たどり着くと選べるようになる (別の登山口から来て見つける)

### 目的地 (ゴール) ─ 天狗山

| 名前 | 標高 | 内容 |
| --- | ---: | --- |
| 滝見台 | 160 | 中腹の大滝を見下ろす展望台 |
| 天狗岩 | 290 | 雲海のすぐ上に突き出した岩。雲の上に出る瞬間が見どころ |
| 双子池 | 350 | 稜線の池。ここから山頂へ3つの道が分かれる |
| 東の肩 | 440 | 山頂の手前の小ピーク。山頂と雲海を一緒に見渡せる |
| 山頂 | 500 | 最終目的地。どの登山口からも行ける。(別の山を足したら、ここに着くと次の山が開く) |

- チェックポイントは目的地にもできる。一度たどり着いたチェックポイントは、地図の上で目的地として選べる
- 登山口と目的地を選ぶと、経路の候補を最大3つ出す (最短、易しい、景色の良い。同じ道になったものはまとめる)。プレイヤーは候補から選ぶか、地図の区間を自分でつないで経路を作る
  - 最短: 目安の時間がいちばん短い。易しい: ★の多い区間ほど遠く数える。景色の良い: 景色の良い区間と展望スポットのある区間を近く数える
  - 区間の目安の時間は、歩き 3.6m/秒、壁 1.2m/秒、難所ひとつにつき 8 秒で見積もる。★は難所の種類と数、帯の高さから決める
  - ロープと鉤縄は向こう岸へ渡るだけなので、その区間は逆向きには使わない。ほかの区間は下りにも使える (壁は降りる)
- 候補には、いま持っている道具で通れる道だけを使う。道具があればもっと近い道があるときは「まだ持っていない道具があれば、もっと近い道がある」と添える
- 経路はあくまで道案内で、登山中に別の道へ入ってもよい。そのときは目的地までの案内を引き直す
- 登山中は画面の端に方位、標高、次のチェックポイントまでの距離を出す。分かれ道には道標を立てる

## チェックポイント

- 種類: 山小屋 (大)、祠 (小)、テント場 (高所のみ)。1区間の目安は1〜4分、高所ほど間隔を短くする
- 広場に入ると到着扱いになり、自動でセーブする (それとは別に、登山中は10秒ごとに経過時間を保存する)
- 広場にいる間は体力とスタミナが全快する
- 山小屋の入口で「使う」と、消耗品 (薬草、携帯食) を1登山につき1回、袋の上限まで補充できる
- 建物・旗・清水は、道の出入口と置いてある物を避けた向きに置く。道標は道ごとに1本立てる
- 一度たどり着いたチェックポイントのうち、いまより低いところへは、一時停止画面の「地図を見る」から一瞬で移動できる (登りの近道にはならない)

## 体力

- ハートで表す。最初は3つ、最大で8つ。画面の左上に出す。ハートは 1/4 ずつ減る
- 減るのは次の2つ
  - 危険な植物に触れる (下の「危険な植物」を参照)
  - 高いところから落ちる (下の「落下」を参照)
- 0 になると、最後に通ったチェックポイントから体力とスタミナが全快の状態でやり直す。それまでに見つけた道具、お守り、展望スポットは失わない (まだチェックポイントを通っていないうちに拾ったものも失わない)。使った消耗品は戻らない
- 回復: チェックポイントに触れる (全快)、薬草を使う (ハート2つ)、清水 (沢や池のそばの湧き水) を飲む (ハート1つ、何度でも)
- 最大値: 山の中にある「お守り」を4つ集めるごとにハートが1つ増える。お守りは祠や難しい道の先に置いてあり、天狗山には20個ある (全部集めるとハート8つ)

### 落下

| 落ちた高さ | 結果 |
| --- | --- |
| 6m 未満 | なにもない |
| 6〜12m | 着地で転んで1秒動けない。ハート 1/2 減る |
| 12〜20m | 2秒動けない。ハート1つ半減る |
| 20m 以上 | ハートが全部なくなる |
| 谷底・滝つぼ (地図の外) | ハートが全部なくなる |

- 落ちた高さは、足場を離れたところと着地したところの差で測る。斜面を転がり落ちたときは、止まるまでの高さの差で測る
- 雪渓の上や深い水に落ちたときは、ダメージを半分にする
- 吊り橋から落ちても、すぐ下に谷底がなければ同じ表で決める (低い橋は落ちても戻れる)

### 危険な植物

| 名前 | 帯 | 触れたとき | 見分け方 |
| --- | --- | --- | --- |
| イラクサ | 麓・中腹 | ハート 1/4 減る。1秒間は同じ草でもう減らない | 道ばたの細かい毛のある草。触れるとチクッという音 |
| ウルシ | 中腹 | 「かぶれ」になる。10秒間、2.5秒ごとにハート 1/4 減る (かぶれている間に触れても長くならない) | 赤みのある葉。秋色の葉が目印 |
| イバラ | 中腹・高所 | ハート 1/2 減り、少し押し返される。壁やロープに巻きついているものは、つかんでいる手が離れる | トゲのあるつる。岩壁やロープに絡んでいる |
| 毒の花 (トリカブト) | 高所 | 花畑の中にいる間、1秒ごとにハート 1/4 減る | 紫の花。花畑はたいてい近道の上にある |

- どれも見て分かるようにし、触れたときに名前と注意を短く出す
- 多くは道の両わきに生えていて、ときどき道の真ん中にもある。そっと歩くと当たり判定が小さくなり、すき間を抜けやすい
- かぶれは清水で洗うか、薬草を使うと治る
- 鉈で刈ったり、手袋で防いだりできる (下の「道具」を参照)。刈った植物はその登山の間は生えてこない

## 道具

- 山の中で見つける。チェックポイントの広場に置いてあるもの、道の途中にあるもの、谷底など道から外れたところにあるものがある
- 道具は一度見つけるとずっと持っている。消耗品は数がある
- 持っている道具は、ほとんどがその場に合わせて自動で使われる (ピッケルは氷の壁につかまると自動で使う)。自分で使う道具は「使う」ボタンで、近くにある使える場所に合わせて選ばれる

### 道具 (ずっと持っているもの)

| 名前 | 天狗山で見つかる場所 | できるようになること | 開く道 |
| --- | --- | --- | --- |
| 鉈 | 南の里の小屋 (最初の区間) | イバラとウルシを刈る (「使う」で振る) | 植物にふさがれた近道 |
| 革手袋 | 東の沢の奥 | イラクサとイバラに触れてもダメージを受けない。雨の日も壁で手が滑らない | イバラの絡んだ岩壁 |
| ロープ | 滝見台 | つるつるの壁 (オレンジの印) の下か上の杭で「使う」と、ロープで登り降りできる。スタミナを使わない | 滝見台から東の岩小屋への近道 |
| 鉤縄 | 天狗岩の先の岩稜 | 谷の向こうの金色の輪に向かって「使う」と、引き寄せられて渡る。ねらいは自動 (輪から谷の幅 + 6m 以内) | 双子池から東の肩への近道 |
| ピッケル | 双子池の小屋 | 氷の壁をつかんで登れる | 北の氷河口からの道、山頂直下の氷の壁 |
| アイゼン | 東の肩への途中 | 雪渓と氷の上で滑らない。強い風でも押されにくい | 山頂域の雪の稜線 |

- 道具ごとに、それがないと通れない区間を各山に1〜2本用意する。どの道具も、なくても山頂へ行ける道は必ず残す
- 新しい道具を見つけると、それで通れるようになった区間の数を知らせる。地図では、道具が要る区間を点線と道具の印で表す

### 消耗品

| 名前 | 効果 | 袋の上限 | 手に入る場所 |
| --- | --- | ---: | --- |
| 薬草 | ハートを2つ回復し、かぶれを治す | 5 | 山小屋、道ばた (白い花で見分ける。登山ごとに生える) |
| 携帯食 | スタミナを全快し、30秒間スタミナの減りを半分にする | 3 | 山小屋 |

- 消耗品は画面の左下のボタンか、キーボードの数字キーですぐ使える
- 消耗品の数は山をまたいで持ち越す

## キャラクターの動き

| 動き | 内容 |
| --- | --- |
| 歩く | ふつうの速さ。吊り橋の上でも揺れが小さい |
| 走る | 速いがスタミナを少しずつ使う。足場が細いところでは踏み外しやすい |
| そっと歩く | とても遅いが、吊り橋とやせ尾根でほとんど揺れない。危険な植物のすき間をすり抜けやすい (当たり判定が小さくなる) |
| ジャンプ | 短い段差と小さな隙間を越える。高さ約 1.1m、距離は歩きで約 2.7m、走りで約 4.5m。空中では向きを少し変えられるが、速くはならない |
| つかまる | 壁、ロープ、鎖、はしごにつかまる。壁に向かって進むと、手の届く高さのホールドを左右の手で自動でつかむ (近くにホールドがなければつかまれない)。壁の上の縁から外へ歩くと、縁をつかんで下向きにぶら下がる (降りられる) |
| 手を動かす (壁) | 画面の左半分をドラッグで左手、右半分で右手 (スマホ・マウス)。キーボードは WASD が左手、矢印キーが右手。パッドは左スティックが左手、右スティックが右手 |
| 地図 | 🗺 ボタンか M キーで、いつでも山の地図を重ねて出す。ゲームは止まらない。もう一度押すかタップで閉じる |
| 手を離す | 壁やロープから離れる |
| 使う | 近くの使える場所に合わせて道具を使う (鉈で刈る、ロープを掛ける、鉤縄を投げる) |

- 坂がきつすぎる (45度より急) と、歩いて登れず滑り落ちる。そこは壁登りか別の道を探す
- 歩いている・そっと歩いているときは、崖の縁 (1m 先が 2.2m 以上低い) で自動で止まる。走っているときと、風に押されているときは止まらない

### スタミナ

- 円形のゲージ (ゼルダのような) で、使っているときだけキャラクターの横に出す
- 走る、壁を登る、ロープにぶら下がる、鎖場を登ると減る。地面に立っていると回復する (1秒で約30%)
- 0 になると壁やロープから手が離れる。ゲージが少ないときは赤く点滅させる
- 標高が上がるほど回復が少し遅くなる (山頂域で 70%)。雨の日は壁で減る量が増える
- スタミナの最大値は、展望スポットを見つけると少しずつ増える (下の「眺め」を参照)

## 難所

### 吊り橋

- 板を並べた橋を、左右のロープで谷に渡したもの。長さ 10〜60m
- 橋は揺れる。揺れは「キャラクターの歩き方」「風」「橋の長さ」で決まる
  - そっと歩く: ほぼ揺れない。歩く: 少し揺れる。走る・ジャンプ: 大きく揺れる
  - 立ち止まると揺れはだんだん収まる
- 揺れが大きいと体が傾く。傾きを表すバランスのゲージを足もとに出し、傾いた方と反対へ移動しようとすると (左スティック・← →・WASD のどれでも、画面で見て反対の向き) 立て直せる。立て直せずに傾ききると落ちる
  - ゲージは画面で見た左右に合わせる (橋の向きとカメラの向きで左右が入れかわらない)。体もゲージと同じ向きに傾けて見せる
  - はじめて大きく傾いたとき「傾いたのと反対へ動くと立て直せる」と一度だけ知らせる
- 高所の橋には「抜けた板」「腐った板 (乗って1秒で落ちる)」「突風 (風の音と旗で予告する)」がある。アイゼンがあると突風で押されにくい
- 揺れは、橋の真ん中がいちばん大きく揺れる振り子として計算する。一歩ごとに左右どちらかへ押し (そっと歩くとほとんど押さない)、突風でも押される。キャラクターは板の動きに乗る
- 傾きは、橋の傾き・揺れの勢い・歩き方で増え、横の入力で戻る。手を放すとゆっくり戻る
- 橋の上では前後にしか進まない。ジャンプで抜けた板を飛び越えられる (橋は大きく揺れる)

### 岩壁 (壁登り)

- 壁には「ホールド」(手でつかめる出っぱり) が並んでいる。つかめるのはホールドだけ
  - つかみやすいホールド: 白く大きい。片手でぶら下がれる時間が長い (3.2秒)
  - つかみにくいホールド: 黒く小さい。片手の時間が短い (1.8秒) うえ、つかんでいる間スタミナが多く減る。雨の日は革手袋がないとときどき滑ってつかめない
  - イバラのホールド: 赤黒い。革手袋がないと、つかむとダメージを受けて手が離れる
  - 氷のホールド: 水色。ピッケルがないとつかめない
  - 壁の上の縁: 端から端までつかめる。両手で縁をつかむ (または片手で縁、もう片手が縁の近く) と登りきる
  - 高いところほど、つかみやすいホールドの割合が減る。オーバーハングはさらに減る。どの壁にも、下から上までつながるホールドの筋を2本以上置く
- 左右の手を別々に動かす。手を動かしはじめると、その手はホールドを離れ、もう片方の手だけでぶら下がる。動かすのをやめた (指を離した・キーを離した) ところにホールドがあれば、つかむ
  - 動かしている手の行き先 (オレンジの点)、届く範囲 (白い輪)、つかめそうなホールド (緑の輪。つかみにくいものはオレンジ、イバラは赤) を壁の上に出す
  - 手が届くのは、つかんでいる手から 1.6m まで
- 片手になったら、ぶら下がっている手のホールドの時間 (上の秒数) 以内に次のホールドをつかまないと落ちる。残り時間はぶら下がっている手のところに輪で出す (少なくなると赤)
- 無理な体勢でも、時間内に直さないと落ちる (2.6秒)。無理な体勢: 両手が 1.75m より離れている、左右の手が交差している、両手の高さが 1.45m より違う
- 両手が離れると落ちる。ホールドのないところで手を止めると、その手は空をつかんだまま (片手のまま) になる
- 体は両手の真ん中の下 (片手なら、その手の下) にぶら下がる。足が地面に着く高さでは地面に立ち、下のホールドへ持ちかえて体が地面より下に来ると、壁から降りる
- スタミナ: 壁にいる間は少しずつ減り、つかみにくいホールドと片手のときは多く減る。はしご・鎖場は半分、オーバーハングは 1.5倍、雨の日は 1.3倍
- 休める出っぱり: 高さ 9m を超える壁には 7m ごとに横長の出っぱりを置く。出っぱりに足が乗っていると、スタミナが回復し、片手・無理な体勢の時間も止まる。出っぱりのすぐ上にはつかみやすいホールドを並べる
- はしご・鎖場は、決まった2列のホールド (つかみやすい) を 0.42m おきに並べたもの
- つるつるの壁はホールドがない。ロープを掛けると、どちらかの手の上下の操作でロープを登り降りできる

### ターザンロープ

- 木や岩から下がったロープ。ジャンプして飛びつくとつかまる
- つかまっている間は、前後の入力で振り子を大きくする。ぶら下がっている間はスタミナがゆっくり減る
- 振りの向きが前になったときに手を離すと、勢いのまま飛ぶ (ジャンプで離すと少し上へ跳ねる)。離すのが早すぎ・遅すぎだと届かない
- 最後のロープから向こう岸へ飛ぶときは、岸を大きく飛び越えたり、あと少しで届かなかったりしないよう、飛ぶ速さを少しだけ助ける
- 着く場所を、地面に輪で示す (麓と中腹だけ。谷へ落ちそうなら赤い輪)
- 1本目のロープは、ふだん手前の岸に寄せてある。ロープを連続でつかみ移る区間もある (高所)。手を離したロープには、着地するまでつかまらない

## 眺め

- 高いところほど遠くまで見えるようにする
  - 霧の濃さ (three.js の `Fog`) を標高で変える。麓は 150m 先から霞み、山頂では 1.5km 先から霞みはじめて 4.6km 先まで見える
  - 雲海の上に出ると、遠くの山並みと海が見える。別の山を足したら、その山も遠くに見えるようにする
- 天狗山には「展望スポット」を20か所置く。多くは高所と、難しい道や道具が必要な道の先にある
  - 立つとカメラが自動でゆっくり景色の方を向き、地名を出す (例: 「天狗岩からの雲海」)。目印は景色の方を向いた案内板
  - 初めて見つけると、カメラが向いたところで写真を撮ってアルバムに入れ、スタミナの最大値が少し増える (4か所ごとに +20%)
- いつでも写真を撮れる「写真モード」を置く (カメラを自由に回す、画面の表示を消す)。自分で撮った写真はアルバムに 12 枚まで残す (古いものから消える)
- 天気で空の色と光、霧の濃さを変える (曇り・雨・霧の順に暗く、見通しが悪い。雨のときは雨粒を降らせる)

## 見た目

### 省電力モード

- ヘッダーの 🔋 で切りかえる。スマホ (指で操作する端末) では最初からオン。選んだ設定は保存する
- オンのとき: 登山中は 30fps (メニューの後ろは 20fps)、描く解像度を 1.25倍までにおさえ、アンチエイリアスを使わない。足もとの細かい地形を 7×7 区画 (オフは 9×9) に狭め、草を約4割、木を約5割に減らす
- オフのとき: 登山中 60fps、メニューの後ろ 30fps

- 地形の色は、標高・傾き・道かどうかで頂点ごとに決める。くぼみは少し暗く、尾根は少し明るくする
- その上に細かい模様 (草・砂利・岩肌) を世界の座標で重ねる。急な斜面は横から見た模様と岩の層 (横縞) にし、遠くでは模様を薄くする (模様は 256×256 の絵1枚)
- 地面の高さに、岩がちな細かい起伏を足す (高いところほど大きい)
- 木は段になった針葉樹と、麓の丸い広葉樹。ほかにハイマツ、岩 (色にばらつき)、キャラクターのまわり 75m の足もとの草
- 遠くの山並みは形にでこぼこをつけ、かすんだ青で描き、高い峰には雪をのせる。空には太陽を描く

## 動作の目安

- スマホで 30fps 以上、パソコンで 60fps
- 地形は、山全体を 12.5m ごとの1枚で描き、キャラクターのまわり (32m 四方の区画を 9×9) だけ 2m ごとの細かい区画に差しかえる。細かい区画は少しずつ作り、全部そろってから切りかえる
- 遠くの山並みと雲海は板と1枚の絵で描く。木・ハイマツ・岩は instancing でまとめて描く
- 動きは 1/120 秒ずつ進め、吊り橋はキャラクターの近く (220m 以内) のものだけ動かす
- 山のデータ (`mountains/<id>.js`) は、その山を選んだときに読み込む

## 確かめ方

- 地形と道は node で作れるので、区間ごとに道の傾き・長さ・目安の時間と、ほかの道の谷や段にかかっていないかを数字で確かめる
- ブラウザ (headless Chromium) で、すべての区間を自動で歩かせて通れることを確かめる (道具はすべて持たせる)
  - 道の点をたどり、橋は横の入力で傾きを戻しながら渡り、抜けた板の手前でジャンプする
  - 壁は登り、休める出っぱりではスタミナが戻るまで待つ。つるつるの壁はロープを掛ける
  - ロープは振って、向こう岸へ向かって手を離す。鉤縄は輪に向かって投げる
- 吊り橋と丸太橋は、傾きを直さずに渡ったときの傾きの大きさを、そっと歩く・歩く・走るで比べる (そっと歩けばほぼ落ちない。風のある橋は直さないと落ちる)

- 夜: 入れるなら、夜にしか開かない道や見えない景色 (町の灯り、星空) と一緒に考える
