# 指揮棒ベートーヴェン（Baton Beethoven）仕様

## 概要

- クラシック音楽に合わせて戦う 2D ベルトスクロールアクション（左右に加えて、奥と手前にも動ける）。主人公はベートーヴェン、武器は指揮棒
- 道中: 夕暮れのウィーンの街。敵は英国紳士たち。曲はモーツァルト「ピアノソナタ第 16 番 ハ長調 K.545 第 1 楽章」（提示部の繰り返しつき、ループ）
- ボス: ヴェルサイユ宮殿 鏡の間のマリー・アントワネット。曲はモーツァルト「ピアノ協奏曲第 21 番 ハ長調 K.467 第 1 楽章」より（ループ）
- 曲の拍（メロディ）に合わせて動くと、ダメージと演出が派手になる。敵の攻撃も拍の上で当たる
- ブラウザだけで動く（Canvas + 素の JavaScript、外部ライブラリなし）。パソコンとスマホ
- 画面の縦横いっぱいに出す。論理的な高さは 540 で固定し、横幅を画面の比率に合わせて広げる（16:9 より縦長の画面では横幅 960 のまま上に空を足し、HUD は画面の上端に置く）
- 画面はいつも横向き。縦長の画面（縦持ちのスマホなど）では、キャンバスを 90 度回して出す（端末を横にして遊ぶ）

## 操作

| 機器 | 操作 |
| --- | --- |
| パソコン | 矢印キー / WASD で上下左右に移動（上下 = 奥・手前）、Space / L / C でジャンプ、J / Z で攻撃（短く押す）、J / Z 長押し → 離すでため攻撃、K / X で防御（押している間）、Esc / P で一時停止 |
| スマホ | 画面の左側（左 45%）をなぞるとスティック（押した所が中心。傾きの強さで速さが変わる。指が遠くへ行くと台がついてくる）。右下の「防」「攻」「跳」。右上の Ⅱ で一時停止 |

- 通常攻撃は押した時刻、ため攻撃は**離した時刻**で拍の判定をする
- 0.2 秒より長く押すと、ための構えになる（ゆっくり歩ける）。0.35 秒で 1 段、0.9 秒で 2 段（最大）。1 段にも届かずに離すと通常攻撃
- 防御ボタンを押したままなら、攻撃などが終わって動けるようになった時点で構える

## ベルトスクロール

- 地面は奥行きのある帯（足もとの画面の高さ 362〜470）。奥ほど人物を少し小さく描き、手前の人物を前に描く
- 奥行きの移動は横の 0.62 倍の速さ。ジャンプ中は奥行きを変えない
- 攻撃が当たるのは、奥行きのずれが 30 以内（ため攻撃は 42 以内、ボスにはさらに +14）。敵の攻撃も同じで、ドレス回転は広い（56 以内）
- 敵は横の間合いと奥行きの両方を合わせに歩いてくる。敵どうしは重ならないように少しずつ離れる
- ケーキは投げた時のプレイヤーの位置（横・奥行き）に落ちる。奥か手前へよければかわせる

## 拍の判定

- 合図（下の帯の音符）: 各拍の頭と、8 分音符の裏でメロディの長い音（8 分以上）が始まる所。16 分音符の走句でも合わせる場所が細かくなりすぎないように
- 合図とのずれ: 0.07 秒以内 = PERFECT（ダメージ ×2.1）、0.135 秒以内 = GREAT（×1.5）、それより外 = 合わず（×1）
- PERFECT / GREAT の一撃は、今鳴っているメロディの音から作った和音をピアノで鳴らす。PERFECT は金の音符・光の輪・画面の揺れ・ヒットストップが大きくなり「BRAVO!」「MAESTRO!」など。最大ためを PERFECT で離すと「FORTISSIMO!!」、五線が画面を走り、音の波が前へ飛ぶ（GREAT 以上で飛ぶ）
- 拍が合った一撃とジャストガードでコンボが増え、コンボ 1 につきダメージ +1%（最大 +50%）。攻撃を受けるか、ガードされるとコンボは 0
- 下の帯（スマホでは画面の上の方）に、近づいてくる合図と、敵の攻撃が当たる拍（黄 = 通常、赤 = ため、桃 = ケーキ）を出す
- タイトルの「タイミング調整」で ±200 ms までずらせる（端末の音の遅れの補正）。音の出力の遅れ（AudioContext の outputLatency）は自動で差し引く

## 三すくみ

通常攻撃 > ため攻撃 > 防御 > 通常攻撃

| こちら \ 相手 | 通常攻撃 | ため攻撃 | 防御 |
| --- | --- | --- | --- |
| 通常攻撃 | 先に当たった方 | **COUNTER!**（ための出かかりをつぶす。ダメージ ×1.4、相手は 1 秒ひるむ） | はじかれて、こちらがよろける。紳士はすかさず反撃してくることがある |
| ため攻撃 | ための途中で受けると、ためが消える | 先に当たった方 | **BREAK!**（防御くずし。ダメージ ×1.3、相手は 1.6 秒ひるむ） |
| 防御 | 防げる（ダメージなし） | **GUARD BREAK**（ダメージ 6 割、こちらがよろける） | — |

## ジャストガード

- 敵の攻撃が当たる拍の 0.2 秒前〜0.08 秒後に防御を押し始めると成功（押しっぱなしで受けたら、ふつうの防御）
- ダメージなし。通常攻撃をジャストガードすると、相手は 1.1〜1.3 秒ひるむ。ため攻撃でも防御くずしを受けない（相手は少しひるむ）
- ケーキをジャストガードすると打ち返して、マリー・アントワネットに 45 ダメージ・ひるみ
- 一度ジャストガードしたら、続けて来る攻撃は構え直さないとジャストにならない（連続攻撃は拍ごとに押し直す）

## 敵

- 敵は拍の頭ごとに次の行動を決める。通常攻撃は 1 拍前、ため攻撃は 2 拍前に予告（頭の上の「!」「!!」と、縮んでいく輪）。輪が重なった拍で当たる
- プレイヤーの様子を見て、勝てる手を選びやすい（ため中には通常攻撃、防御中にはため攻撃、通常攻撃を続けると防御）
- 同時に攻撃してくるのは 1 体（4 つ目の波から 2 体）まで

| 種類 | 体力 | 特徴 |
| --- | --- | --- |
| 紳士（シルクハット・片めがね・ステッキ） | 55 | 釣り合いのとれた型。防御は傘 |
| 執事（銀のお盆） | 42 | 速い。通常攻撃が多い。防御はお盆 |
| 伯爵（山高帽・太め） | 120 | 遅い。ため攻撃と防御が多い。防御は傘 |

- 倒すと 35%（体力 40 未満なら必ず）で楽譜を落とす。拾うと体力 +18

## 道中

- 長さ 4500 px（横）。決まった位置に来ると画面が止まり、敵の波と戦う（全 5 波: 1・2・2・3・5 体。同時に出るのは 3 体まで）
- 最初の 4 波では、遊び方のヒントを画面の上に出す
- 全部倒して右端まで行くと、暗転してヴェルサイユ宮殿へ

## ボス: マリー・アントワネット

- 体力 900。登場から 2 小節（8 拍）は名乗りの演出で、攻撃しない。通常攻撃ではひるまない（COUNTER と BREAK とジャストガードではひるむ）
- 技: 扇子打ち（通常・1 拍）、扇子の連打（通常 ×3。1 拍おき、後半は半拍おき）、ドレス回転（ため・2 拍・広い）、ケーキ投げ（通常扱い。投げた 1 拍あとの拍に、投げた時のプレイヤーの位置に落ちる。後半は 3 連投）、扇子の防御
- 体力が半分を切ると後半: 紳士と執事を 1 人ずつ呼ぶ。連打が速くなる
- 倒すとスローモーションと最後の和音で終演。結果画面へ

## 点数とランク

- 与えたダメージ × 10 ×（1 + 判定）、COUNTER / BREAK +300、ジャストガード +800、撃破 +500（ボス +20000）、波を片づけて +1000、ケーキの打ち返し +1500
- クリア時: (100 − 受けたダメージ) × 100 + 残り体力 × 50
- ランク: 拍に合った割合 =（PERFECT + GREAT × 0.6）÷ 攻撃の回数。S = 55% 以上かつ受けたダメージ 80 以下（最初から遊んだときだけ）、A = 40% 以上、B = 20% 以上、C
- ハイスコアと、タイミング調整の値は localStorage に保存（保存できなくても遊べる）

## 画面の流れ

- タイトル（遊び方・三すくみの図・タイミング調整）→ 道中 → ボス → 結果
- 結果: クリア = もう一度 / タイトル。ボスで負けた = ボスから / 最初から / タイトル
- 一時停止すると曲も止まる。タブを離れたら自動で一時停止

## 音

- 拍と音は AudioContext の時計で合わせる（曲は 0.25 秒先まで予約して鳴らす）
- ピアノは作曲家サバイバーの録音（`../composer-survivors/samples/piano/`、Salamander Grand Piano V3, CC BY 3.0）を共有して使う。読みこむまでは合成の音
- ボス曲の弦・低音・ティンパニは合成（のこぎり波 + ローパス、サイン波）。小さなホールの残響をかける

## 曲のデータ

- `scores/k545.js`: Mutopia Project の MIDI（Alejandro Sierra 浄書、CC BY-SA 3.0、https://www.mutopiaproject.org/ftp/MozartWA/KV545/K545-1/）から `tools/build_k545.py` で作る。提示部（1〜28 小節）の繰り返しを元の形に戻している。このファイルも CC BY-SA 3.0
  - 作り直し: `python3 -I tools/build_k545.py K545-1.mid`
- `scores/k467.js`: 自由に使える譜面のデータが見つからなかったので、このゲームのために書いた 24 小節の短い編曲（行進曲風の冒頭の主題 → ピアノ独奏の走句 → 主題をピアノと重ねて）。原曲の音とは違うところがある。音名で手書きしていて、`audio.js` の `parseText` が読む
