# 作曲家サバイバー 遊び方の試作

どの遊び方が一番楽しいかを比べるための試作。本編 (`../`) には手を入れず、同じ曲・同じ音符・同じピアノの音で 3 つを遊べる。

- 開き方: `games/composer-survivors/proto/`（検索には出さない `noindex`）
- 全 15 曲・3 人の指揮者・難しさ 3 段（やさしい / ふつう / シビア）を最初から選べる
- 遊んだあとに ★1〜5 とメモを残すと、メニューの「比べる」の表に遊び方ごとの回数・クリア・平均の評価・最近のメモが出る（この端末の localStorage だけに保存）
- 音符の強さは本編と同じ考え方（高い音は速く脆い・低い音は遅く硬い、短い音は脆い・長い音は硬い、♪ の倍率、音符の多い曲ほど 1 つずつは弱い）。この試作には練習室がないので、「ふつう」は本編で練習室を半分ほど上げたくらいに合わせた

## 試作 1: 横スクロールの陣取り（`lane.js`）

- 右のボスから音符が左へ進み、左の指揮台から楽団員（7 種）を送り出す。楽団員は右へ進み、出会った音符と戦う
- 楽団員は体力を持ち、ダメージを受けきると消える（退場）。最大 12 人
- 音符は先頭の楽団員にせき止められ、叩く。指揮台に届くと体力が減る
- **高い音（高音域）は宙を飛ぶ**: 前線に止められず、遠くを撃てる楽器（ヴァイオリン・フルート・トランペット）しか当てられない。どの楽器を出すかの理由になる
- インクは時間でたまる。インク壺を強化すると早くたまり、上限も上がる。楽器ごとに出したあとの待ち時間がある
- 指揮者の一振り: 32 秒でたまる大技。近くの音符をまとめて削って押し戻す
- キー: 1〜7 楽団員、W インク壺、Space 一振り

## 試作 2: 見下ろし（五線譜）（`topdown.js`）

- 今の五線譜のまま、音符の流れを逆にした（左のボス → 右の指揮台）
- タワーは体力を持ち、同じ高さ（行）を流れてきた音符をせき止める。止められた音符はタワーを叩き、ダメージを受けきったタワーは壊れる
- ハープの弦だけはせき止めない（通りぬける音符を削る）
- 強化（Lv3 まで。体力も戻る）・修理・売る（2 回押しで確定。強化の直後は押せない）
- 準備の時間があり、「開演」で曲が始まる。決戦ではボスが右へ進み、触れたタワーを壊していく
- キー: 1〜7 タワーを選ぶ、U 強化、R 修理、Space / Enter 開演

## 試作 3: 縦のシューティング（`shooter.js`）

- 音符は上から降ってくる。横の位置は音の高さ（左ほど低い。曲の音域を横いっぱいに広げる）
- 作曲家をドラッグ（矢印キー / WASD）で動かし、弾は自動で撃つ。下の鍵盤の線を越えた音符と、ぶつかった音符で体力が減る
- アクセントの付いた強い音符とフェルマータは、こちらへ弾を撃つ
- 落とした音符はインクの粒を落とし、自分に吸い寄せられる。インクでソロ（弾の本数）を強化するか、補助のタワー（5 種、最大 6 つ）を置く
- タワーは音符に触れると削られ、壊れる（触れた音符は遅くなる）
- 一振り: 40 秒でたまる。敵の弾を消し、画面の音符をまとめて削る
- 決戦ではボスが左右に動き、曲ごとの形（放射・狙い撃ち・扇）で弾を撒く
- キー: 1〜5 タワーを選ぶ、Q ソロ強化、Space 一振り
